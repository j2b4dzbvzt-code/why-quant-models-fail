## 1. 策略解释的对象：一条完整的决策链

策略解释不能止于“模型认为上涨概率是 60%”或“特征 A 排名第一”。应能逐层回答：

1. 机会来自什么可检验的经济机制？
2. 信号预测的对象、期限和可交易时点是什么？
3. 方向优势、胜率和赔率如何估计，是否校准？
4. 为什么承担这么大的仓位，而不是更大、更小或不交易？
5. 多笔下注、同一资产多信号和多个策略如何汇总？
6. 哪些损失、相关性、流动性和制度情景会使策略失效？
7. 什么证据会触发降仓、暂停或推翻当前解释？

要明确区分：

| 对象 | 例子 | 不能直接推出什么 |
|---|---|---|
| 特征/信号 | 盈利意外、动量、波动状态、订单流 | 不能仅凭相关性宣称因果 |
| 预测 | 上涨概率、预期收益、波动预测 | 不能直接推出资金该投入多少 |
| 目标仓位 | 方向×规模、风险目标、组合权重 | 不能当成实际成交或持仓 |
| 实际投资结果 | 持仓、现金流、费用、冲击、已实现损益 | 不能只用预测准确率代替 |

一个可以复核的策略解释，需要将信号、仓位、约束、执行和结果分开留痕。这样才能把问题定位为预测错误、概率失准、风险裁剪、组合冲突，还是执行成本。

## 3. 建立策略解释前先锁定口径

### 3.1 先说清楚策略命题

把策略写成可以被推翻的句子：

> 在什么时点，用哪些当时可见的信息，对什么标的、预测哪种结果，在什么持有/退出期限内，按什么仓位和约束承担风险；相对哪个基准，什么样的样本外证据算支持，什么结果会否定它？

至少预先固定收益目标（价格收益、总回报、超额收益、净收益或效用）、证券池、时钟、基准、风险预算、交易成本口径和验证样本。每次改变信号、标签、阈值、仓位算法、股票池或评价指标都要留版本；不要把优化过后的对象仍称为最初的预设策略。

### 3.2 概率、方向与赔率不能混用

模型输出 0.7 只有在目标明确并且概率校准后，才可能被解释为约 70% 的某类事件概率。例如：

- 未来固定期限正收益的概率；
- 方向主模型判断正确的概率；
- 先触及三重障碍中止盈障碍的概率；
- 扣成本后净收益为正的概率；
- 订单在限价和时限内成交的概率。

这几种概率的事件不一样。同一个数字不能互换。分类模型输出经常只是排序分数；类别权重、抽样比例、状态漂移和重叠样本都会改变概率的校准含义。校准必须用不参与拟合/调参的时间段检查，并按目标市场和状态复查。

### 3.3 先建立可解释基准

至少保留一种无模型或简单仓位基准：不交易、等权、固定风险单位、只用原始信号、只用主模型方向、概率阈值策略或简单买入持有。复杂仓位只有在独立样本上增加净效用、风险调整后结果或其他预定目标，才有理由取代简单基准。

## 4. 下注规模：把优势映射到风险承担

### 4.1 盈亏平衡概率

设一笔同方向交易以概率 p 获得收益 g，以概率 1-p 亏损 l，成本 c 与仓位单位对应。单笔期望净收益：

\[
EV=p g-(1-p)l-c
\]

期望值转正的最低胜率为：

\[
p_{BE}=\frac{l+c}{g+l}
\]

胜率不是孤立的策略质量指标：胜率高但平均盈利小、平均亏损大，也可能负期望；胜率低的趋势策略若盈利远大于亏损，也可能有正期望。实际 g、l、c 会受市场状态、仓位、流动性和执行方式影响，因此盈亏平衡点也应做区间分析。

### 4.2 下注单位与风险标准化

先确定 size 的单位。可选名义金额、组合权重、目标波动风险、止损金额、保证金占用或风险资本。仓位 \(q_t\) 的意义不同：

- 名义仓位相同，波动率不同，风险不同；
- 波动率目标仓位相同，跳跃、流动性和相关性仍可能不同；
- 止损风险相同，跳空穿越止损时实际损失仍可能超标；
- 组合风险贡献相同，集中在同一行业/宏观因子时仍可能同跌。

常见风险缩放形式是 \(q_t\propto R_t/\hat\sigma_t\)，其中 R 是该策略/标的的风险预算，\(\hat\sigma_t\) 是点时风险尺度。该公式只有在波动估计和收益单位相容、可成交性足够、仓位约束可执行时才有意义。分母接近零时必须设置上下限和异常状态规则。

### 4.3 概率转仓位：简单映射与限制

在对称赔率、概率已校准的简化分类场景中，可先用 \(2p-1\) 表示方向净优势：p=0.5 对应零，p 越远离 0.5，方向置信度越高。再用缩放因子、死区、风险目标和上限约束形成仓位。此只是可解释基准，不是普适最优仓位。

若策略主信号已给出 side，元模型预测的是主信号成功概率，则概率低于盈亏平衡门槛通常表示不交易/缩小该方向，而不是自动反向下注。反向仓位要由独立的反向机会、成本和风险检验支持。

### 4.4 Kelly 公式：理论标尺，不是实盘默认值

考虑一次二元下注：正确时每投入 1 单位净赢 b，错误时亏 1 单位；资金的 f 比例投入该下注。长期期望对数增长为：

\[
G(f)=p\log(1+b f)+(1-p)\log(1-f)
\]

求导并令其为零，得到理想化全 Kelly：

\[
f^*=p-\frac{1-p}{b}
\]

只有当 p 超过盈亏平衡率 \(1/(1+b)\) 时，f* 才为正。该结果假设胜率和赔率已知、下注可重复、资金按固定比例复利、没有约束且模型正确；真实金融策略中概率误差、厚尾、交易成本、下注相关和跳空可能令全 Kelly 仓位过大。若采用 fractional Kelly，应把比例、最大仓位和概率误差情景明示，并用样本外与压力情景检验。

### 4.5 一个保守的概率仓位示例

以下代码将概率映射为方向仓位，只演示一个可复算的基准。它采用对称盈亏近似，以死区减少微小预测导致的频繁交易，并以 maximum 限制仓位；参数必须在训练/验证设计内选择。

~~~python
import numpy as np

def symmetric_probability_size(
    probability_up,
    maximum=1.0,
    dead_zone=0.03,
    shrink=0.25,
):
    """
    对称盈亏假设下的示意仓位：
    输出范围 [-maximum, maximum]，正数做多、负数做空。
    不是 Kelly，也不是对未经校准分数的通用解释。
    """
    p = np.asarray(probability_up, dtype=float)
    if np.any(~np.isfinite(p)) or np.any((p < 0.0) | (p > 1.0)):
        raise ValueError("probabilities must be finite and within [0, 1]")
    maximum, dead_zone, shrink = map(float, (maximum, dead_zone, shrink))
    if (not np.isfinite([maximum, dead_zone, shrink]).all()
            or maximum < 0 or dead_zone < 0 or shrink < 0):
        raise ValueError("maximum, dead_zone and shrink must be finite and non-negative")

    edge = 2.0 * p - 1.0
    raw = shrink * edge
    raw = np.where(np.abs(edge) < dead_zone, 0.0, raw)
    return np.clip(raw, -maximum, maximum)
~~~

真实系统还应输入概率置信区间、波动率、净赔率、费用、可成交容量和组合限额；概率较不确定时可向零仓位收缩。若目标是“已有方向信号是否采用”，应采用与该方向的净收益标签一致的元标签概率映射，不能直接套用上涨概率。

### 4.6 活跃下注、平均与离散化

第10章把下注规模放在持有区间内考虑：旧下注可能仍活跃，新预测到来时不一定要完全覆盖旧仓位。原书 Snippet 10.2 对同一时点仍活跃的下注取**简单算术平均**，以减少覆盖式换仓；这不是按置信度或剩余持有时间加权。若实务采用加权汇总，应明确标为扩展规则，说明权重和共同风险处理，再施加总敞口与风险限制。

仓位离散化的动机是减少小幅信号扰动导致的无意义换手。设置死区/档位后，会牺牲一部分小信号响应、换取更低交易成本。阈值不能通过完整回测反复挑选；应检查周转率、漏掉的大信号和不同市场下的净效用。

限价单的限价与数量也共同决定成交概率、等待成本、排队优先级和 adverse selection。不能在历史模拟中假设限价单只在有利时成交，却忽略未成交和价格先走掉的情况。不同市场、venue、订单类型和时段需要独立的执行概率模型。

### 4.7 按原书公式把概率和并发信号转换成仓位

上面的 `symmetric_probability_size` 是一个刻意简化的教学基准，直接使用 $2p-1$ 表示对称二元事件的净方向优势。它**不是**第10章 Snippet 10.1 的原式。书中的方法先把预测概率相对“无信息基准概率”标准化，再用标准正态分布函数映射到仓位。

二分类时，若正类概率为 $p$，无信息基准是 $1/2$：

\[
z=\frac{p-1/2}{\sqrt{p(1-p)}},\qquad m=2\Phi(z)-1.
\]

多分类时，以最大类别概率 \(\tilde p=\max_i p_i\) 与均匀基准 \(1/K\) 比较：

\[
z=\frac{\tilde p-1/K}{\sqrt{\tilde p(1-\tilde p)}},\qquad
m=x\,[2\Phi(z)-1],
\]

其中 $x$ 是预测类别对应的方向/下注标签，$K$ 是类别数。Meta-labeling 中，主模型提供方向，次模型判断“下注/跳过”：把次模型的通过概率按二分类公式转成非负规模，再乘主模型方向。未通过时仓位为零，不应把它误解释为自动反向做空。

~~~python
import numpy as np
from scipy.special import ndtr

def afml_probability_size(max_class_probability, predicted_label, n_classes):
    """第10章 OvR 概率到仓位映射；predicted_label 为方向/类别对应的下注值。"""
    p = np.asarray(max_class_probability, dtype=float)
    x = np.asarray(predicted_label, dtype=float)
    if (not isinstance(n_classes, (int, np.integer))
            or isinstance(n_classes, (bool, np.bool_)) or n_classes < 2):
        raise ValueError("n_classes must be an integer of at least 2")
    if p.shape != x.shape:
        raise ValueError("probabilities and predicted labels must have the same shape")
    if np.any(~np.isfinite(p)) or np.any((p < 0) | (p > 1)):
        raise ValueError("invalid class count or probability")
    if np.any(~np.isfinite(x)):
        raise ValueError("predicted labels must be finite")
    if np.any((x < -1.0) | (x > 1.0)):
        raise ValueError("predicted labels must encode a bet in [-1, 1]")
    # 避免 p=0/1 时分母为零；极端概率被限制在数值开区间。
    eps = np.finfo(float).eps
    p = np.clip(p, eps, 1.0 - eps)
    z = (p - 1.0 / n_classes) / np.sqrt(p * (1.0 - p))
    size = 2.0 * ndtr(z) - 1.0
    return np.clip(x * size, -1.0, 1.0)
~~~

该映射隐含类别概率有意义且与目标标签定义一致。若 `predict_proba` 未校准、类别极不平衡或训练/部署分布发生变化，$m$ 只是模型分数的单调变换，不是未来收益大小的估计；还要在独立前向样本上检查校准、换手、成本和仓位分布。

第10章还给出与预测置信度不同的**并发下注容量缩放**。令 $c_{t,l}$、$c_{t,s}$ 分别为时点 $t$ 仍未结束的多头、空头信号数量，净并发数 $c_t=c_{t,l}-c_{t,s}$。一种做法是在历史 $c_t$ 上拟合双高斯混合，取其 CDF $F$，并定义：

\[
m_t=\begin{cases}
\dfrac{F(c_t)-F(0)}{1-F(0)},&c_t\ge0,\\[4pt]
\dfrac{F(c_t)-F(0)}{F(0)},&c_t<0.
\end{cases}
\]

另一种更简单的预算法是分别用最大值或选定分位数归一化多头和空头并发数：$m_t=c_{t,l}/C_l-c_{t,s}/C_s$。两种方法回答“并发信号如何共享有限仓位预算”；概率映射回答“单个预测有多强”，不能混成同一口径。并发分布和上限也只能用决策时可得的历史信息估计。

### 4.8 价格变化时动态调整目标仓位

第10章 10.6 节把预测目标价 $f$ 与当前价 $p_t$ 的差 $x=f-p_t$ 映射为动态目标仓位：

\[
m(\eta,x)=\frac{x}{\sqrt{\eta+x^2}},\qquad
\hat q_t=\operatorname{int}\{m(\eta,f-p_t)Q\},
\]

其中 $Q$ 是最大绝对仓位，$\eta$ 控制曲线宽度。价格趋近预测目标时，目标仓位逐渐回到零，以实现已有盈利；校准点 $(x,m^*)$ 对应 $\eta=x^2((m^*)^{-2}-1)$。逆函数为 $L[f,\eta,m]=f-m\sqrt{\eta/(1-m^2)}$，原书据此计算订单增减仓过程中各单位仓位的盈亏平衡限价。实际限价还需考虑买卖方向、最小价位、队列位置、部分成交和 adverse selection；理论限价不等于保证成交价。原书还给出 $\operatorname{sgn}(x)|x|^\eta$ 作为替代曲线，曲率参数同样应以前向样本和执行成本选择。

## 5. 仓位如何进入组合：集中度、相关性与 HRP

### 5.1 组合层比单笔信号多一层问题

多个单笔高质量预测可能全部暴露于同一风险源，例如利率、美元、成长风格、流动性或某个行业。组合层要考虑：

- 总净敞口、总毛敞口、杠杆和融资；
- 资产波动及相关性在不同状态下的变化；
- 单票、行业、国家、币种、期限和主题集中度；
- 预期换手、交易成本、容量和同步平仓能力；
- 策略之间是否真的独立，还是共享数据、标签和持仓；
- 投资期限、风险贡献与负债/基准约束是否匹配。

均值—方差优化会使用协方差矩阵和预期收益；当输入估计有噪声时，最优化过程可能把小误差放大为极端权重。HRP 将资产相关关系转为层次结构，通过聚类排序后递归分配，避免显式求协方差矩阵逆；但它仍依赖历史协方差/相关结构，不会自动消除估计误差、 regime shift 或交易约束。

组合解释还可展示每个资产对组合波动的边际贡献。令权重为 w、协方差矩阵为 Σ，组合波动为 \(\sigma_p=\sqrt{w^\top\Sigma w}\)，资产 i 的波动风险贡献可写成：

\[
RC_i=\frac{w_i(\Sigma w)_i}{\sigma_p}
\]

在权重不含短仓且风险矩阵正常时，各资产风险贡献之和等于组合波动。若要比较资产/策略的风险占比，可再除以 \(\sigma_p\)。相关性上升可能令原先分散的风险贡献迅速集中，所以应对常态和压力相关矩阵都做归因；风险贡献不是收益贡献，也不直接给出最优仓位。

### 5.2 HRP 的逻辑

HRP 的实务步骤可以概括为：

1. 从训练窗口内的收益估计协方差与相关矩阵，固定估计窗口和频率。
2. 将相关系数转为距离，例如 \(d_{ij}=\sqrt{(1-\rho_{ij})/2}\)。
3. 用层次聚类得到树结构，并按叶节点顺序对资产做 quasi-diagonalization，使相似资产相邻。
4. 递归将排序后的资产簇分成左右两组；分别估计组内逆方差权重和组方差。
5. 按相对组风险分配左右簇权重，再递归到单资产。
6. 施加实际投资约束，按下一可执行时点的交易规则调仓。

书中数值实验用于论证其在特定模拟与数据条件下可能改善样本外风险，不代表 HRP 总是优于等权、风险平价或优化器。聚类树会随相关矩阵、距离和 linkage 选择变化；小样本、强相关或状态切换时需报告权重不稳定性。

### 5.3 HRP 教学实现

下面的实现用于理解层次聚类和递归二分。要求输入是对齐的 pandas 协方差矩阵、资产名唯一且对角方差为正。它不处理换手/税费、短仓、行业约束、风险预算和矩阵估计；实际组合须在每个历史训练窗口重估，不可用全样本协方差回填过去。

~~~python
import numpy as np
import pandas as pd
from scipy.cluster.hierarchy import leaves_list, linkage
from scipy.spatial.distance import pdist

def hrp_weights(covariance):
    cov = pd.DataFrame(covariance, dtype=float)
    if (
        cov.empty
        or cov.shape[0] != cov.shape[1]
        or cov.index.has_duplicates
        or cov.columns.has_duplicates
        or set(cov.index) != set(cov.columns)
    ):
        raise ValueError("covariance must be square with unique asset names")
    cov = cov.loc[cov.index, cov.index]
    values = cov.to_numpy()
    if not np.isfinite(values).all() or not np.allclose(values, values.T, rtol=1e-10, atol=1e-12):
        raise ValueError("covariance must be finite and symmetric")
    variances = np.diag(values)
    if np.any(variances <= 0):
        raise ValueError("all asset variances must be positive")
    eigenvalues = np.linalg.eigvalsh((values + values.T) / 2.0)
    eigen_scale = max(1.0, float(np.max(np.abs(eigenvalues))))
    if eigenvalues.min() < -1e-10 * eigen_scale:
        raise ValueError("covariance must be positive semidefinite")
    if len(cov) == 1:
        return pd.Series([1.0], index=cov.index, name="weight")

    vol = np.sqrt(variances)
    corr = values / np.outer(vol, vol)
    corr = np.clip((corr + corr.T) / 2.0, -1.0, 1.0)
    np.fill_diagonal(corr, 1.0)
    distance = np.sqrt(np.clip((1.0 - corr) / 2.0, 0.0, None))
    # AFML Snippet 16.4 将距离矩阵的每一行作为距离画像，再算行间欧氏距离。
    profile_distances = pdist(distance, metric="euclidean")
    tree = linkage(profile_distances, method="single")
    order = list(cov.index[leaves_list(tree)])
    weights = pd.Series(1.0, index=order)

    def cluster_variance(names):
        sub = cov.loc[names, names].to_numpy()
        inv_var = 1.0 / np.diag(sub)
        within = inv_var / inv_var.sum()
        return float(within @ sub @ within)

    clusters = [order]
    while clusters:
        next_clusters = []
        for cluster in clusters:
            if len(cluster) <= 1:
                continue
            mid = len(cluster) // 2
            left, right = cluster[:mid], cluster[mid:]
            var_left = cluster_variance(left)
            var_right = cluster_variance(right)
            if var_left <= 0 or var_right <= 0:
                raise ValueError("cluster variance must be positive")
            left_weight = 1.0 - var_left / (var_left + var_right)
            weights.loc[left] *= left_weight
            weights.loc[right] *= 1.0 - left_weight
            next_clusters.extend([left, right])
        clusters = next_clusters

    weights = weights.reindex(cov.index)
    return (weights / weights.sum()).rename("weight")
~~~

本例按 AFML Snippet 16.4 的输入约定，将 $D_{ij}=\sqrt{(1-\rho_{ij})/2}$ 的每一行作为一个“距离画像”，再由 `pdist(D, metric="euclidean")` 计算画像之间的欧氏距离，并交给 `linkage` 做单链接聚类。若使用 `squareform(D)`，则把 $D_{ij}$ 直接作为资产之间的成对距离，是另一种常见聚类口径，不等于原书的“distance of distances”。原书单链接与簇内逆方差权重同样影响结果。研究时应明确口径，与其他 linkage、滚动估计窗、收缩协方差和简单基准比较，并以外层前向样本评价，不要把代码输出当成稳健的最优权重。

## 6. 策略风险：胜率、赔率、频率与失败

### 6.1 书中定义的策略失败概率

策略风险不等同于标的波动或投资组合回撤。第15章对每年 $n$ 笔 IID 下注、精确率 $p$、亏损 $b_-<0$ 与盈利 $b_+>0$ 推导年化 Sharpe：

这里的 $p$ 是实际采取的下注中盈利结果的比例（precision），不是把“跳过/不下注”也纳入分母的整体分类准确率；跳过机会主要通过改变每年下注频率 $n$ 影响 Sharpe。

\[
SR(p,n,b_-,b_+)=\frac{\sqrt n\,[p b_+ +(1-p)b_-]}{(b_+-b_-)\sqrt{p(1-p)}}.
\]

对称输赢 $b_-=-b_+$ 时，下注金额会抵消，$SR=\sqrt n(2p-1)/(2\sqrt{p(1-p)})$。给定投资人目标 $SR^*$，由赔率、频率和目标反解最低精确率 $p^*$。书中定义的策略失败概率是：

\[
P_{fail}=P(p<p^*).
\]

其中阈值是由同一二项收益模型反解得到的最小可行值：

\[
p^*=\min\{p\in[0,1]:SR(p,n,b_-,b_+)\ge SR^*\}.
\]

原书 Snippet 15.3 对不对称输赢的反解可写成：

~~~python
import numpy as np

def required_precision(stop_loss, profit_taking, bets_per_year, target_sr):
    """AFML Ch.15 的最低精确率反解；stop_loss 应为负数。"""
    sl, pt = float(stop_loss), float(profit_taking)
    n, sr = float(bets_per_year), float(target_sr)
    if (not np.isfinite([sl, pt, n, sr]).all()
            or not (sl < 0 < pt) or n <= 0 or sr < 0):
        raise ValueError("require stop_loss < 0 < profit_taking, n > 0, SR >= 0")
    a = (n + sr**2) * (pt - sl) ** 2
    b = (2 * n * sl - sr**2 * (pt - sl)) * (pt - sl)
    c = n * sl**2
    disc = b**2 - 4 * a * c
    if disc < 0:
        return np.nan  # 给定规则下目标 Sharpe 不可达
    p = (-b + np.sqrt(disc)) / (2 * a)
    return float(p) if 0 <= p <= 1 else np.nan
~~~

估计时，从历史下注收益估计平均亏损/盈利与年频率；若投资人的评估期为 $h$ 年，原书 IID 重采样基线每次抽取约 $n h$ 个下注结果以形成精确率分布，再计算其落在 $p^*$ 左侧的概率。它回答“这套策略能否达到目标”，不是资金终值亏损或途中破产概率。原书第15章给出了 IID 重采样/KDE 思路；其代码中的正态近似不宜直接照抄：`scipy.stats.norm.cdf` 的 `scale` 参数是标准差，不是方差，且应计入有限样本量。对重叠持仓、序列依赖或状态切换，应使用区块/状态条件重采样。

策略也可能在较高精确率下因不对称赔率而亏损，或以较低精确率靠较大盈利/损失比获得正期望；因此须同时呈现精确率、赔率和下注频率，不能单报准确率。

作为另一个、不同的问题，以固定单位下注、单笔相互独立为例，获胜次数 \(K\sim Binomial(n,p)\)，累计损益 \(S_n=Kg-(n-K)l\)。若终值损失达到 D，则：

\[
k_{\max}=\left\lfloor\frac{nl-D}{g+l}\right\rfloor,\qquad
P(S_n\le -D)=\sum_{k=0}^{k_{\max}}\binom{n}{k}p^k(1-p)^{n-k}
\]

若 \(k_{\max}<0\)，上述终值损失概率为零；若其已覆盖全部可能获胜次数，概率为一。这个二项式是期末损失阈值诊断，**不是**书中 $P(p<p^*)$ 的策略失败概率，也不计算途中触及保证金线的概率。

~~~python
import numpy as np
from math import floor
from scipy.stats import binom

def terminal_loss_probability(n, p, win, loss, loss_limit):
    """IID 固定单位下注下，期末累计损益不高于 -loss_limit 的概率。"""
    if (not isinstance(n, int) or isinstance(n, bool) or n < 1
            or not np.isfinite([p, win, loss, loss_limit]).all()
            or win <= 0 or loss <= 0 or loss_limit < 0):
        raise ValueError("n, win and loss must be positive; limit non-negative")
    if not 0.0 <= p <= 1.0:
        raise ValueError("p must be within [0, 1]")

    max_wins = floor((n * loss - loss_limit) / (win + loss))
    if max_wins < 0:
        return 0.0
    if max_wins >= n:
        return 1.0
    return float(binom.cdf(max_wins, n, p))
~~~

本函数只算期末累计损失越线，不计算中途先触及破产线的路径概率；不要将其直接标成策略失败率或真实破产率。

### 6.2 终值亏损不等于路径破产

上式计算的是期末损益低于阈值的概率，不是期间任何时点触及保证金线、最大回撤或投资者止损线的首次通过概率。要评估路径失败，应模拟交易顺序和复利：

- 资本低于初始值某比例、保证金不足或风险预算突破时停止；
- 单笔仓位随信号、波动、成本或资产净值变化；
- 下注结果在行业、因子、波动状态和市场时段内相关；
- 跳空和无法成交造成的实际亏损可能超出名义止损。

对简单模型可以计算终值二项概率；对真实策略应使用保留依赖结构的区块/状态条件重采样、压力期回放或路径模拟，并把概率估计的不确定区间一起报告。将交易顺序随机打散会低估连续亏损和流动性挤兑风险。

### 6.3 胜率估计有误差时的风险

即使事件在样本内可近似二项，胜率 p 也是估计值。样本有限、状态漂移和筛选偏差会使估计的置信区间较宽。仓位若按点估计的全 Kelly 推算，可能在 p 被高估时过度投入。至少要：

1. 给出概率估计区间和校准结果；
2. 用保守概率（例如下置信界或收缩估计）重算 EV/仓位；
3. 做胜率、赔率、交易频率、成本和相关性联合压力分析；
4. 预估连续亏损和最大回撤，而不只看平均值；
5. 将估计误差映射到仓位收缩、硬限额或暂停规则。

## 7. 回测危险：策略解释不应由净值曲线反推

出版方对第11章的章节结构概括了几个核心议题：所谓“无瑕回测”的难题、即使实现没有明显错误回测仍可能误导、回测不应充当研究工具，以及策略选择中的偏差。回测是一个依赖假设的历史模拟，不能像受控实验一样单独证明因果。

### 7.1 解释策略前先排除几类伪证据

| 风险 | 怎样让解释失真 | 该问什么 |
|---|---|---|
| 多重试验/选择偏差 | 在很多规则中挑最高回报，把极值误当稳定规律 | 共测试过多少标签、参数、资产池、过滤器和版本？ |
| 前视/时间戳错误 | 用收盘后公告按当日收盘价交易、使用未来修订数据 | 每个特征的可用时间是否早于决策和订单时点？ |
| 幸存者/退市遗漏 | 只用当前仍上市证券，自动丢掉失败公司 | 历史证券池和退市收益是否完整？ |
| 标签/特征泄漏 | 训练和验证共享标签路径，或全样本拟合预处理 | 所有区间型信息是否 purge，估计器是否折内拟合？ |
| 不现实成交 | 以 OHLC 中间价、止损价或限价价假设必然成交 | 是否处理队列、延迟、跳空、部分成交和不可交易状态？ |
| 成本低估 | 忽略冲击、借券、费用、汇率和换手 | 净收益的成本分解是否与账户、市场和容量匹配？ |
| 会计不完整 | 复权价格被当成订单价，漏掉分红、股数或换月现金流 | 价格研究序列与实际持仓账本是否分开？ |
| 基准不公平 | 复杂策略仅胜过现金，却未胜过简单风险/风格基准 | 风险、杠杆、行业、币种和市场暴露是否匹配？ |
| 容量忽略 | 小资金有效被解释成大资金可用 | 目标资金量下的参与率、冲击和退出时间是多少？ |
| 结果复用 | 反复看测试集并改策略，最后仍称“样本外” | 测试集是否真正冻结；改动后是否重新设立前向样本？ |

“没有发现代码 bug”不等于数据口径正确；“口径正确”不等于策略有因果性；“毛收益为正”不等于成本后可实施。对策略解释而言，应把证据按层标示，而不是用一张累计收益图概括全部结论。

### 7.2 把回测当成待审计的策略评价

研究假设要由经济机制、先验文献、交易约束和可观测机制提出；回测用于评价冻结假设在给定历史数据和执行假设下的表现。若是探索性发现，应称候选策略并登记探索过程；不能因为策略是在回测里发现的，就又用同一段回测证明它成立。

主题四会进一步展开 walk-forward、purging、回测过拟合、基准比较、净值统计与成本模型。主题三的最低要求是：策略的主张和仓位规则先写清楚，开发/验证/测试边界先锁定，所有尝试记账，执行假设按时点可实现。

### 7.3 多次试验下的策略选择偏差

第11章还用 CSCV 估计回测过拟合概率 PBO。先把每次试验/策略配置的同步损益整理成 $T×N$ 矩阵，按时间把 $T$ 行切成偶数个连续块；枚举每次取半数区块作 IS、其余作 OOS 的组合。在每个组合中选 IS 指标最好的策略，计算该策略在 OOS 的相对排名 $\omega$，并取对数几率 $\lambda=\log(\omega/(1-\omega))$。PBO 是 $\lambda<0$ 的组合占比，也就是 IS 冠军在 OOS 落到中位数以下的频率。

CSCV 的随机化单位是连续时间块，块内顺序保留；它不是逐行随机切分，也不能替代按时间推进的部署前向验证。它要求所有候选损益同步、各块长度一致，且评价指标可在子样本上计算；策略选择次数必须完整记录，候选矩阵若漏掉尝试，PBO 也会被低估。完整切分、泄漏和报告规范归入主题四。

## 8. 可解释性：分别解释模型、仓位和组合

### 8.1 三种常被混成一种的解释

- **模型解释**：哪些输入让模型输出改变？用系数、置换重要性、SHAP 或局部解释查看。
- **下注解释**：预测如何通过优势、风险尺度、概率校准和硬限额转为仓位？
- **策略/组合解释**：收益来自哪些资产、时间、因子和市场状态？亏损来自哪些共同风险和执行环节？

模型解释可能受相关特征替代、特征尺度、背景样本和分布改变影响；特征归因并不能证明“这个变量造成了收益”。策略解释应同时提供决策路径和结果归因，并展示不使用该信号/改变该约束的反事实。

### 8.2 研究报告可以固定的解释表

| 层级 | 建议展示 |
|---|---|
| 机制 | 行为假设、参与者/约束、何种市场状态下成立 |
| 信号 | 定义、数据时点、可用时点、预测目标、校准和样本外稳定性 |
| 仓位 | 目标风险、概率/优势映射、死区、上限、限额裁剪和调仓原因 |
| 组合 | 风险贡献、行业/国家/币种/因子暴露、集中度和相关性压力 |
| 实现 | 下单价、成交率、滑点、费用、借券/保证金和持仓现金流 |
| 失效 | 监控阈值、历史例子、动作、负责人和恢复标准 |

每次解释还应标注“事实”“估计”“假设”和“决策”。比如预测概率是估计，未来市场状态是假设，仓位上限是治理决策，成交记录是事实。标签区分能减少把模型输出包装成市场事实的误读。

### 8.3 标签、集成与特征重要性怎样支撑策略解释

第3章的标签设计决定模型概率究竟表示什么。固定期限标签在不同波动环境下使用同一阈值，且忽略止盈/止损前的价格路径；三重障碍标签用波动率目标设水平障碍、用持有期限设垂直障碍，以先触及者定义结果。方向未知时可用对称水平障碍学习方向与规模；已有主方向时，元标签只判断“接受还是跳过”，标签为 0/1，方向仍由主模型给出。这个拆分让胜率、规模与方向可分别解释，但障碍、波动率目标和执行价的定义仍会改变标签经济含义。

第6章把集成误差分为偏差、方差和不可约噪声。Bagging 通过重采样平均预测降低方差；若基模型预测之间的平均相关性接近 1，增加模型数几乎不再降方差。金融事件标签重叠会让 bootstrap 样本高度冗余，并使 OOB 准确率偏乐观；不能把多个相关模型的投票当成多个独立收益来源。随机森林再随机抽取特征以降低树间相关性，但不能修复标签重叠和时间泄漏。Boosting 逐次强调错分样本，可能同时降低偏差和方差，也更容易在低信噪比金融数据上过拟合；应以适当的时间序列验证和样本权重评价。

第8章讨论三种互补的特征重要性：MDI 是树模型的训练内 impurity 降幅，快速但可能有掩蔽、类别数偏差和相关特征替代问题；MDA 在样本外置换单列，衡量性能损失，但高度相关的替代特征会互相遮蔽，置换还可能制造不现实的特征组合；SFI 单独使用每个特征做样本外预测，不受同类替代影响，却会漏掉只有交互时才有效的特征。可用训练折内标准化的 PCA 缓解线性共线，不会消除非线性替代或证明因果。书中还比较跨证券并行汇总与先堆叠证券数据：前者便于并行但重要性排序可能跨资产互换，后者增加样本量但要求合理标准化，且需控制证券间分布差异。特征重要性用于研究特征与机制，不能直接推出因果、收益或仓位。

### 8.4 结构突变、熵和微观结构信号的边界

第17章提供三类可作为策略状态输入的诊断：CUSUM 检测递归预测误差或价格水平偏离；Chow 型/ADF 家族检测随机游走与爆炸性过程切换，SADF 用滚动终点和后向扩展起点搜索多个泡沫区间；QADF、CADF 试图减轻极端 ADF 值带来的不稳健；子/超鞅趋势检验还可使用多项式、指数或幂函数形式。书中强调对长时间序列优先考虑对数价格，并指出 SADF 计算量高。阈值、最小窗口、滞后、抽样频率都会影响结果；多个窗口取最大值本身也带来极值选择偏差。结构突变分数应描述当前证据和不确定性，不能直接宣称“泡沫必然破裂”或机械择时。

第18章把熵当作序列信息/复杂度特征，而不是方向预测。Plug-in 熵依赖有限窗口中词频的经验分布；Lempel–Ziv/Kontoyiannis 方法利用重复子串长度估算压缩率。连续收益需先编码：二元符号适用于波动较均衡的事件/成交量类 bar，分位数编码令训练期各码频率接近，sigma 编码则用固定数值间隔切分收益范围。编码边界、字母表大小、词宽和窗口决定熵估值；训练期分位数边界必须固定后应用于未来，避免用未来样本重估。有限样本、非平稳和编码选择都可能主导数值，所以应比较多种窗口/编码并用合成数据校准；高熵既不等于上涨，也不必然等于可交易机会。

第19章从逐笔成交、报价和订单消息构造流动性/执行特征：tick rule 估计主动买卖方向；Roll 用价格变动负自协方差估计有效价差；高低价估计波动和 Corwin–Schultz 价差适用于缺少集中订单簿的情境；Kyle、Amihud、Hasbrouck lambda 用签名成交量/成交额解释价格冲击；PIN/VPIN 试图刻画信息型交易和量时钟下的买卖不平衡。订单规模分布、撤单/限价/市价单、TWAP 执行节奏、期权成交和签名订单流自相关也可作为候选特征。原书明确指出 tick rule 只是分类近似，报价未必可成交，VPIN 的预测证据存在争论。实务中，主动方标签、行情覆盖、撮合规则、venue、时间同步和成交成本误差会直接传导到特征；撤单率高不能单独证明欺诈或某类参与者意图。第19章最后把微观结构信息定义为相对于做市商预测能力的交叉熵损失，说明“信息”必须相对于具体决策模型和结果标签来衡量。

## 9. A 股与美股的策略落地差异

策略解释的共同框架相同：把方向、优势、风险、仓位、组合和实现分开；但具体参数要由当地数据和账户约束校准。

| 方面 | A 股要特别说明 | 美股要特别说明 |
|---|---|---|
| 可成交性 | 涨跌停、停牌、集合竞价、T+1、板块/证券状态、卖空限制 | 多 venue 路由、盘前盘后、熔断/限价机制、borrow/locate 和召回 |
| 风险退出 | 触发止损可能仍无法卖出；排队和隔夜跳空会扩大实际损失 | 借券成本/可得性变化、交易场所分散、开收盘流动性和延长时段报价质量 |
| 组合身份 | 行业/主题集中、历史上市/退市、公司行动和对冲工具约束 | ADR 与 share class 映射、并购/拆分、退市证券、ETF 与美国市场多 venue |
| 账户成本 | 佣金/税费/融资融券按账户和日期处理，规则变化留版本 | 佣金、场所费用/回扣、借券费、融资、监管费用和路由依账户而变 |
| 计价风险 | 跨市场组合时说明人民币账户的汇率转换时点 | 非美元证券或跨境资产须拆开本币收益与美元汇兑影响 |
| 时间结构 | 交易日历、午间休市、盘后公告与次日可交易时间 | 美东时区、夏令时、半日市、盘前盘后与各市场开放时间 |

现行交易细则和费用不是静态常数。将规则/费率做成带生效日期的配置表，历史研究读取历史版本；不要把当前页面上的规则套回全部历史，也不要仅靠市场标签变量代替逐项约束。

## 10. 三类策略的解释模板

### 10.1 A 股日频横截面选股

解释顺序可采用：

1. 在历史可投资证券池中，以盘后已知数据计算信号；报告公告的实际可用时点，避免当日收盘价既算特征又假设成交。
2. 用排序分数决定候选组；如将其转成胜率，先校准“未来哪个期限、扣不扣成本、以何种价格成交”的概率。
3. 从下一可执行时点开始建仓，单票规模受风险预算、流动性、涨跌停和停牌状态限制；T+1 等规则按历史规则版本入账。
4. 按目标持有期限、事件终止或风险条件退出。止损信号触发但无法卖出时，持仓仍留在账本中，继续承受风险。
5. 将收益拆为选股、行业/风格、现金、交易和公司行为部分，再与行业中性/简单风险基准比较。

解释“模型看多某只股票”时，应该说明预测证据、概率/排序含义、目标仓位和限制后仓位各是多少，以及涨停无法买入或停牌延续时风险如何记账。

### 10.2 美股财报事件或长短仓策略

财报首次公开的时点可能落在常规交易时段之外；信号应在下一实际可交易时点计算/下单。对于多头和空头，分别估计赔率、成交条件和费用；空头仓位要将借券可得、费用变化和召回风险与方向预测分开。若使用盘前盘后报价，要检验该时段的点差、深度和下一常规开盘跳空。

策略说明至少展示：财报事件方向判断、概率校准、元模型是否接受主方向、按波动/赔率产生的目标仓位、借券与组合约束、实际执行滑点，以及事件后漂移是否覆盖成本。只报告公告后某个收盘价到另一个收盘价的均值，无法证明策略可实现。

### 10.3 多策略或多资产资金分配

先让每个子策略独立生成已校准的预测和风险标准化收益，再用同一币种、同一频率和一致费用口径汇总策略收益序列。用等权、风险单位和 HRP 等方法做对照，解释权重差异由波动/相关结构还是预期收益驱动。设定单策略权重上限，避免历史低波动或短暂低相关造成资本集中。

实务报告同时呈现权重、波动风险贡献、共同因子暴露、回撤、换手和成本。若两策略共享信号、数据、持仓或退出规则，不应仅因策略名称不同就认为相关性估计已经捕捉全部共同风险。

## 11. 常见误读与修正

| 误读 | 更准确的解释 |
|---|---|
| “准确率高，所以仓位应该大” | 还需赔率、成本、校准、风险预算、相关性和容量 |
| “Kelly 是最优，所以全 Kelly” | 只在一组强假设下最大化长期对数财富；估计误差会造成严重过度下注 |
| “HRP 不求逆，所以没有估计风险” | 它缓解矩阵求逆/优化不稳定，仍依赖协方差、相关距离、聚类与样本窗口 |
| “分散了股票，所以风险分散了” | 共同因子、行业、币种、流动性和危机相关性可能令风险重新集中 |
| “回测没有 bug，所以策略有效” | 数据、假设、多重试验、市场变化和不可成交仍会让结果失真 |
| “SHAP 解释了模型，所以找到了因果” | 归因解释模型条件关联，因果需要额外识别设计与反事实 |
| “净值最大回撤可代表最大可能风险” | 历史回撤依赖所观察的样本、仓位和流动性；不能覆盖未见的尾部路径 |

## 12. 交付前检查清单

- [ ] 策略机制、收益来源、目标期限和反证条件能一句话说清。
- [ ] 预测概率的事件定义明确，已校准或明确标为分数/未校准概率。
- [ ] 方向、仓位、限额后仓位和实际持仓分字段记录。
- [ ] 仓位映射公式可复算，赔率、成本、风险单位和最大值透明。
- [ ] Kelly/HRP 等方法写出假设，并与等权、风险单位等基准比较。
- [ ] 活跃下注、方向冲突、重复信号和多策略共同暴露有合并规则。
- [ ] 终值损失与路径破产/回撤风险区分；策略失败概率交代依赖假设。
- [ ] 历史回测没有被当作提出并证明假设的同一证据；多重试验可追溯。
- [ ] A 股和美股分别校准交易规则、费用、做空、时区和数据覆盖。
- [ ] 结果能按模型预测、风险裁剪、组合配置、交易执行逐层归因。
- [ ] 降仓、暂停和重启条件有数值门槛、数据来源和复核责任。

策略解释最终要形成可质疑、可复算、可被新证据推翻的决策说明。它不是一段替历史业绩辩护的文字，而是把收益主张、仓位选择和风险承担放到同一套透明规则里。
