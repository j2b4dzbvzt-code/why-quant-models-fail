# 提取可复用信号：量化研究顺序流程

> **英文摘要（English summary）：** A step-by-step process for proposing, constructing, validating, and documenting reusable quantitative signals. It emphasizes point-in-time features, target design, temporal validation, experiment tracking, and evidence that survives changes in time and market conditions.

> **文件定位**：这是一份独立的量化研究流程文件，回答“先做什么、后做什么、用什么口径、为什么这样筛选、怎样判断信号是否能复用”。它与[原理手册](./原理.md)分工不同：本文件按实际研究顺序组织工作；原理手册解释各方法的原理、适用条件、代码范式、A股与美股差异和失效边界。
>
> **适用范围**：本流程聚焦从数据中提出、构造、检验并交付可复用信号。信号有效不等于组合可盈利；完整的仓位、交易成本、容量和投资组合回测应与后续策略及回测可信度主题衔接。
>
> **依据**：主要对应《Advances in Financial Machine Learning》第1—9、17—19、22章，并将书中方法改写为现代点时研究流程。跨专题映射见根目录《机器学习算法与量化专题映射.md》，本专题的章节核对见配套原理手册。

## 一、先统一“信号”的定义

量化研究中至少要区分五层对象：

| 层次 | 含义 | 示例 |
|---|---|---|
| 原始观测 | 市场或经济事实及其原始记录 | 成交、报价、财报公告、订单簿更新 |
| 特征 | 在决策时点已知、由原始观测计算的变量 | 过去20日波动率、订单流不平衡、财报意外 |
| 标签 | 研究者定义的未来结果，用来训练和评估 | 未来收益、是否触及止盈、信号是否盈利 |
| 模型信号 | 模型对未来结果的估计 | 方向概率、预期收益、成交概率、风险评分 |
| 交易决策 | 将预测变成订单、仓位和风险约束 | 买入、减仓、观望、限价单或不交易 |

“可复用信号”不是某个模型里偶然出现的高分特征。它至少要有清楚的经济解释、稳定的计算定义、明确的信息可用时间、可跨样本验证的增量信息，并且在新的证券、时段或合理市场状态中没有立即失效。若没有这些条件，应称为待检验特征，而不是已确认信号。

## 二、研究主链

~~~text
写清楚研究主张和决策时点
  → 确定当时可投资的证券与数据可用范围
  → 将经济机制翻译为可观测数据和特征
  → 选择采样时钟与事件定义
  → 定义未来标签及实际结果口径
  → 处理重叠标签、样本唯一性和样本权重
  → 只用训练窗口拟合特征变换
  → 采用符合时间结构的验证、调参和样本外测试
  → 检验特征增量、稳定性、替代解释和失效状态
  → 将信号封装成可追溯、可监控、可复现的研究组件
~~~

不能把这条链倒过来：先遍历大量指标、看到历史收益最好的一项再编经济故事，会引入严重的多重试验和选择偏差；先用全样本估计标准化、分位数或差分参数，再切训练集，也会把未来分布信息带入过去。

## 三、按先后顺序执行

### 第1步：把研究问题写成可证伪的主张

开始取特征前先写一页研究卡：

| 项目 | 必须写清楚的内容 |
|---|---|
| 经济机制 | 谁在什么约束下产生何种行为？为什么这种行为可能持续？ |
| 预测对象 | 方向、收益幅度、波动、流动性、成交概率、违约风险，还是某个事件？ |
| 决策时点 | 盘前、开盘、盘中、收盘后，或信息发布后多久？ |
| 预测区间 | 从哪个可执行时点开始，到哪个事件/时刻结束？ |
| 适用对象 | A股、美股、ETF、期货、期权；行业、流动性和市值范围？ |
| 成功标准 | 预测指标、增量信息、分层单调性、稳定性，还是扣成本后的策略效用？ |
| 预期失效 | 哪些制度、状态、容量或数据条件会使机制不再成立？ |

主张要能被反驳。例如：“财报首次公开后，经过点时标准化的盈利意外，在财报可交易时点之后的数日内仍能解释横截面总回报；对比规模、行业和流动性基准有增量；按公告可用时间、停牌和交易成本处理后成立。”这比“财报因子有效”更可检验。

**停止条件**：无法明确决策时点、标签起点或经济机制时，暂不进入模型搜索。

### 第2步：锁定历史上真实可见的数据与证券池

从主题一的数据整理流程继承数据治理要求。每条输入至少有证券身份、事实时间、首次公开时间、系统可用时间、修订版本、来源和转换版本。历史时点 t 的特征只能使用在 t 已经可用的信息。

先固定：

1. **点时证券池**：当时上市、未退市、符合交易限制且可投资的证券；不能用当前成分股回填历史。
2. **信息准入时点**：公告、财报、宏观统计的首次公开时间、供应商到达时间及解析完成时间。
3. **制度版本**：交易日历、涨跌幅、熔断、竞价、最小报价单位、做空和交收规则按生效日期保存。
4. **修订策略**：财报重述、宏观修订、供应商更正、成交撤销分别保留版本；回测应能重放当时版本。
5. **缺失语义**：区分“没有发生”“未覆盖”“未公开”“停牌”“供应商缺报”和“不可交易”，不要把它们统统补成零。

**为什么这一步先于特征工程**：幸存者偏差、公告未来可见和错误证券映射会改变标签与特征的关系，之后再精致的模型也修不回来。

### 第3步：从机制走向变量，不从变量堆走向故事

每个候选信号沿着“行为机制 → 可观测量 → 变换 → 特征 → 预测对象”逐层记录。例如：

| 层次 | 示例：短期流动性压力 |
|---|---|
| 机制 | 订单簿变薄时，小额净卖压也可能造成更大价格冲击 |
| 观测 | 成交方向、成交额、价差、盘口深度、价格变化 |
| 变换 | 统一时间戳和单位；将成交方向质量作为字段；按过去窗口聚合 |
| 特征 | 单位净卖出流量对应的价格冲击、价差/深度变化 |
| 预测 | 下一可交易区间的冲击成本、流动性恶化概率或条件收益 |

特征注册表至少写：定义、公式、单位、方向预期、频率、窗口、事件时间、可用时间、证券适用范围、缺失处理、拟合参数、源数据、代码版本和失效条件。多个高度相似的特征应先分组，避免把重复代理变量当成多个独立发现。

### 第4步：选择采样时钟和事件集合

先问“什么构成一个研究样本”，再生成标签。可用日历时间、固定时间柱、成交量柱或成交额柱（volume/notional bars）、订单流事件或公告事件。高频市场中，日历等间隔不等于信息到达等间隔；活动时钟也不自动使样本独立或平稳。

| 问题 | 常用样本定义 | 适用时机 | 关键控制 |
|---|---|---|---|
| 日频横截面收益 | 每个市场收盘/下单时点一条证券样本 | 因子排序、组合调仓 | 各市场交易日历和收盘时差 |
| 盘中价格行为 | 时间 bar、成交量 bar、成交额 bar | 预测短期收益或波动 | 阈值只能由过去数据估计；不完整尾 bar 要标记 |
| 订单流/流动性 | 订单簿变化、成交事件、volume bucket | 预测短期冲击或执行质量 | 方向分类误差、队列与场所覆盖 |
| 财报/宏观事件 | 首次可交易的事件时点 | 信息扩散、事件反应 | 公布时间、修订版本、同时事件与市场休市 |

如果事件由 CUSUM 或阈值触发，阈值的估计只能来自过去数据，需记录事件覆盖率和不同波动状态下的采样变化。事件过滤可能改善信噪比，也可能只保留特定市场状态，必须报告被过滤样本的分布。

### 第5步：先确定标签，再决定模型

标签定义的是“什么结果算成功”，不能由特征或最后的策略收益临时反推。

1. **固定时间区间标签**：适合明确持有期问题；收益区间必须从信号可执行之后开始。
2. **动态阈值标签**：以点时波动率、风险预算或经济阈值定义显著结果，避免相同百分比对高低波动证券含义不同。
3. **三重障碍标签**：为每个事件设置止盈、止损和最长持有时间；首次触及水平障碍结束事件，未触及时由垂直障碍收尾。
4. **元标签**：已有主信号给出方向时，第二层只判断“这次要不要采取该方向”，或估计其可靠度/仓位，不要让元模型偷换方向标签。
5. **成本相关标签**：若研究问题是是否值得交易，收益应扣除可执行时点对应的费用、价差、冲击、借券/融资和汇兑成本；成本模型本身也要防止未来信息。

三重障碍与元标签的细节、A股涨跌停/停牌和美股盘前盘后处理见[原理手册](./原理.md)。OHLC bar 若上下障碍在同一根 bar 内都被穿越，单靠 OHLC 不知道触碰顺序；应使用更细粒度数据、保守顺序假设或标记歧义，不能选择对策略最有利的顺序。

### 第6步：识别标签重叠并处理样本依赖

一个标签区间内可能有多个并发事件；同一段价格变化因此被多次计入训练样本。先计算每个时点的标签并发数 c_t，再用事件区间内 1/c_t 的平均值衡量样本唯一性：

$$
u_i=\frac{1}{|T_i|}\sum_{t\in T_i}\frac{1}{c_t}
$$

按目标采用平均唯一性、收益归因或其他样本权重，并单独考虑时间衰减和类别不平衡。三类权重解决不同问题，不要未经检验就机械相乘；权重应归一化并比较加权/不加权结果。顺序自助抽样可提高样本集合的增量唯一性，但不使时间序列变成独立同分布。

**门槛**：报告标签重叠率、有效样本数、不同权重方案结果；若重叠极高，应调整采样或验证方式，而不是仅靠一个权重“修复”。

### 第7步：在训练窗口内拟合特征变换

每个变换都要回答：需要估计参数吗？参数何时可得？训练、验证、实时如何复用？

- 缺失填补、行业中性化、缩尾、标准化、分位数映射、PCA、筛选阈值和阈值事件规则，只在训练窗口拟合，再应用到验证/测试。
- 滞后、滚动波动率、滚动分位数等特征，确保窗口右端不越过当前决策时点。
- 分数阶差分可在价格保留部分记忆与平稳性之间折衷；对候选差分阶数 d 做训练窗口内选择，报告平稳性检验和与原序列的相关性，不把“通过单位根检验”误说成有预测力。
- 熵和微观结构特征必须明确编码、单位、时段和覆盖范围；熵是序列复杂度代理，不天然等于方向；价差和订单流模型则依赖具体行情数据质量。

### 第8步：建立时间可信的验证与调参设计

普通随机 K 折可能把相邻观测和重叠标签拆到训练、测试两边。验证设计按“部署问题”选择：

| 验证目的 | 优先方案 | 注意 |
|---|---|---|
| 模拟上线后往未来预测 | 按时间向前滚动的 walk-forward | 最接近部署；训练数据只能早于测试决策时点 |
| 评估重叠事件标签 | Purged CV + embargo | 按标签信息区间剔除与测试区间重叠的训练事件；它不自动等于因果部署测试 |
| 选择超参数并估计泛化误差 | 嵌套时间验证 | 外层评估、内层调参；不能先看外层结果再反复修改 |
| 多市场/多证券迁移 | 留出市场、行业、证券或时间段 | 检查信号是否仅记住单一市场/个股 |

把最终 lockbox 在所有设计决策冻结前保持不可见。若研究者在看过测试结果后改了特征、标签、股票池、阈值或模型，这一段就不再是未触碰测试集。

### 第9步：由简单基准到复杂模型

顺序建议：无技能基准 → 线性/单变量基准 → 树或集成模型 → 复杂模型。每一步都要回答“相对上一层增加了什么样本外信息”。类别不平衡时可报告 PR-AUC、balanced accuracy、log loss 等；概率型输出还要检查校准。预测指标不能代替经济目标，但经济收益也不能绕过成本和组合约束。

集成方法要结合样本量、噪声、相关性和部署限制选用。Bagging 可以降低不稳定估计的方差；Boosting 可能更灵活，也更容易追逐噪声；没有一种在所有金融数据上必胜。若重叠事件使 bootstrap 样本高度重复，袋外误差不应当作独立样本外证明。

调参用有限且事前定义的搜索空间，乘法尺度参数通常适合对数尺度抽样。调参评分须与目标对应，不能只追逐最高准确率；每次搜索、随机种子、数据截止点和候选空间都要留痕。

### 第10步：检验信号是否有增量且稳定

对候选信号至少做四层检查：

1. **增量**：相对经济基准、已有因子、行业/规模/流动性控制和主信号，它是否增加样本外信息？
2. **消融**：去掉该特征、整组特征或交互后，表现变化多大？单变量重要性不等于组合中的边际价值。
3. **稳定性**：分年份、波动状态、市场、行业、流动性、做多/做空和不同合理数据供应商检查方向与幅度。
4. **反证**：打乱标签、构造纯噪声/冗余变量、改变合理窗口、错开事件时间、扣更多成本后，是否还出现不合理强结果？

MDI、MDA、SFI各有偏差：MDI可能偏好类别多/可切分点多的变量；MDA受相关替代变量影响；SFI忽略特征交互。对相关变量，考虑组级置换、成组消融或正交化后的解释，并报告相关性结构。

### 第11步：把信号封装成可复用组件

信号交付物至少包括：

- 数据依赖和字段口径，源表版本与许可/覆盖范围；
- 特征定义、单位、窗口、时区、决策可用时间、缺失和异常语义；
- 训练时估计的参数、版本、刷新频率和历史回放方式；
- 标签定义、样本权重、训练和样本外时间段、验证拆分；
- 基准模型、预测指标、成本假设、适用证券和已知失效状态；
- 实时输出 schema、延迟预算、质量告警、漂移监控和停用条件；
- 可复现实验记录、代码提交、随机种子、环境/API版本。

**信号接口建议**：输出预测值或概率、置信度、as-of 时间、数据质量标记、模型版本和适用范围；由组合层另行施加仓位、风险、流动性和交易约束。不要让特征函数暗中决定“买多少”。

## 四、按数据类别快速套用

### A. 日线价格与成交量

先确定目标是价格方向、波动、总回报还是可交易收益；处理拆股/分红一致性与退市样本；用信号实际可下单之后的价格构造标签；按点时证券池做横截面。成交量、换手率、波动率和技术因子按市场日历计算，停牌和涨跌停导致的不可成交要保留为状态，不要填成普通零收益。

### B. 财报、公告、宏观与分析师数据

保留原始披露、首次公开时间、供应商到达时间、修订时间与有效期。以公告首次可交易时点对齐；财报季度期末不是可见时点。比率指标要处理分母接近零、币种/会计口径和重述；宏观数据保存实时版本，避免最终修订值回填历史。跨频率前向填充必须设置经济有效期和 freshness 标记。

### C. 盘中成交、报价和订单簿

先处理时区、序号、撤销/更正、特殊成交条件和重复包，再按具体 venue/feed 说明覆盖范围。美股单 venue direct feed 不等于全市场订单簿，SIP 综合行情也看不到全部隐藏流动性；A股逐笔数据的字段覆盖、委托队列和竞价阶段要核验供应商定义。之后再估主动方向、价差、深度、冲击和订单流特征。所有高频预测都明确订单提交与成交延迟。

### D. 期货、期权、跨资产和另类数据

期货信号同时保存逐合约报价、换月规则、乘数、保证金、期限结构和真实滚动盈亏；连续合约仅作研究特征，不把拼接价差当成可交易收益。期权特征保存合约规格、到期、行权价、隐波口径、报价质量及希腊值估计版本。跨资产对齐不同交易时段、币种与可用时间。另类数据应能证明合法可用、当时可获得、覆盖稳定并可进行历史版本重放。

## 五、最小交付检查清单

- [ ] 研究主张能被反驳，目标与决策时点明确。
- [ ] 样本只含当时已知信息和当时可投资证券。
- [ ] 特征所有估计型变换均由训练窗口拟合。
- [ ] 标签从真实可执行时点开始；公司行为和成本口径匹配目标。
- [ ] 标签区间、重叠率、唯一性和权重方案有记录。
- [ ] 验证集按部署目的设计；调参与最终评估隔离。
- [ ] 与基准相比有样本外增量，并做市场/时段/状态稳定性检查。
- [ ] 检验特征替代、数据缺陷、错误时间戳、噪声基线和成本压力。
