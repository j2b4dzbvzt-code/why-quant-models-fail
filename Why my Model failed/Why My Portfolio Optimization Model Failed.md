# 投资组合优化模型为何失效（Why My Portfolio Optimization Model Failed）

> **英文摘要（English summary）：** This report traces portfolio failure to noisy expected returns, unstable covariance, infeasible constraints, turnover and market impact, and accounting shortcuts. It compares mean-variance, minimum variance, risk parity, Black–Litterman, robust optimization, CVaR, and hierarchical allocation, connecting target weights to executable orders and account-level results in A-share and U.S. markets.

## 投资组合优化为什么会失败：估计误差、约束、交易与真实账本

优化器只会在给定目标、预测量、约束和成本模型内找数学上的解。它不会替研究者证明收益预期正确、协方差稳定、约束可执行或回测可成交。组合“最优”经常是输入误差经优化放大的结果：权重看起来精确，真实风险却没有更低。

本文覆盖均值—方差、最小方差、风险平价、Black–Litterman、稳健优化、CVaR/尾部风险、层次聚类配置及带交易成本的动态组合。示例框架不构成任何真实市场的收益保证。

## 1. 把预测、配置、交易三个问题分开

组合研究至少包含三个映射：

1. **预期量估计**：预期收益 μ、风险/协方差 Σ、尾部分布和相关结构来自何处？
2. **决策优化**：目标函数是什么？绝对收益、跟踪误差、风险预算、回撤、流动性或多目标约束如何权衡？
3. **实施交易**：目标权重如何变成订单、成交、费用、现金、借券和公司行动？

这三个结果不能混为一谈。预测 IC 良好不代表组合有效；优化器输出一组权重不代表订单能成交；回测权重曲线也不是账户现金流。

一个经典均值—方差形式是：

\[
\max_w \quad \hat\mu^T w-\frac{\lambda}{2}w^T\hat\Sigma w-C(w-w_{prev})
\]

受预算、集中度、行业/风格、流动性、杠杆、卖空、换手和风险限制约束。这里每个输入与成本项都带估计误差。目标项、约束、可行域和交易方式必须和实际账户一致。

## 2. 不同配置模型的边界

| 方法 | 强项 | 常见失效 |
|---|---|---|
| 均值—方差 | 可表达收益-风险偏好与视图 | 对预期收益误差高度敏感；极端多空权重；正则化不足 |
| 最小方差 | 不必估计预期收益 | 协方差估计误差、危机相关性跳变、集中到历史低波资产 |
| 风险平价 | 按风险贡献分配，减少直接依赖均值 | 风险模型错误、杠杆与波动目标失真、不同风险类别不可比 |
| Black–Litterman | 将均衡先验与有不确定性的视图结合 | 先验、风险厌恶、视图置信度和协方差口径不一致 |
| 稳健/分布鲁棒 | 在参数集合或分布集合内控制最坏情形 | 不确定集过窄无保护、过宽退化；集合设定本身仍需验证 |
| CVaR/尾部风险 | 关注损失尾部而非仅方差 | 尾部样本有限、极端样本权重高、回测尾部不代表未来尾部 |
| HRP/聚类配置 | 结构化使用相关关系，减少矩阵直接求逆 | 聚类结构仍不稳定；相关距离、链接方式与窗口选择影响分配 |
| 1/N、基准/规则组合 | 透明、低估计负担，适合强基线 | 不自动满足风险、目标、容量和客户约束 |

均值—方差优化的样本估计风险及样本外退化有大量研究讨论；比较方法时应把简单规则作为正式基准，而非把优化器复杂度当作优势。[估计误差下优化组合的样本外表现](https://pubsonline.informs.org/doi/10.1287/mnsc.1060.0664)；[协方差收缩方法](https://doi.org/10.3905/jpm.2004.110)

## 3. 失败机制

### 3.1 输入微小变化导致权重剧烈变化

若小幅修改预期收益、协方差窗口、资产池或约束便令权重翻转，优化器是在追逐噪声。检查权重对时间窗、估计器、采样误差、预期收益缩放和风险厌恶参数的响应；报告权重分布而不是只给一次最优解。

### 3.2 预期收益的统计误差超过信号本身

年化均值很小而估计窗口有限，误差会轻易支配收益差异。均值—方差目标又直接按 μ 排序，使偏高的估计更容易取得更大仓位。可比较均值收缩、因子先验、置信区间/不确定集、仅风险目标和 1/N 基线，但所有选择需在时间外评估。

### 3.3 协方差病态和危机结构改变

高维下样本协方差可能近奇异；优化器利用微小的特征值或低估相关性放大风险。使用收缩、因子、稳健或其他适当估计器并做条件数、正定性和状态敏感性诊断。静态相关性难以覆盖相关性在压力期上升。

### 3.4 约束写得像现实，数值却不等于可执行

连续权重不一定能变成最小交易单位；行业/风险暴露计算口径也可能错位；无卖空、借券不足、限仓、集中度或交易单位在某些日期会令问题不可行。不可行时用松弛变量、逐层优先级与显式报告，不能静默放宽限制。

### 3.5 忽略换仓路径和非线性成本

若目标在日频频繁改变，线性手续费仍可能低估价差、冲击、成交概率、借券费和市场容量。成本随参与率、流动性、时段和订单类型非线性变化。要把成本放入决策或约束，并以仿真/执行记录核准，而不是事后按一个平均基点扣除。

### 3.6 用收益矩阵而非账户账本计算绩效

复权价格、现金分红、拆并股、停牌和退市收益若口径不一致，会造成组合收益错位。目标仓位、下单、部分成交、现金和实际持仓必须逐时衔接。净值应从可复算现金流与持仓市值推导。

### 3.7 调参、资产池筛选和回测共用样本

在同一时期选资产、估计参数、调风险阈值、修改成本、比较策略再报告冠军，是隐性多重试验。保留所有尝试；嵌套训练、调参、验证和最终时间外评估。增加数据点或更密的再平衡网格不会自动增加独立证据。

## 4. 组合优化完整研究流程（pipeline）

1. **定义账户与目标**：基准、投资期限、计价货币、风险预算、可接受回撤、杠杆/做空和流动性边界。
2. **点时资产池**：保留历史成分、上市退市、行业分类、停牌/不可交易日、证券身份和公司行为版本；明确收益与复权口径。
3. **构造估计器**：以过去可见数据估计预期收益、协方差、因子/尾部风险；所有变换和 shrinkage 参数在每个训练窗口内估计。
4. **建立基准配置**：至少包含目标基准/市值加权、等权、最小方差或透明规则中与任务匹配的基线。保持交易频率和约束可比。
5. **定义优化问题**：单位与年化口径一致；写出目标、全部约束、软约束/罚项和不可行时的处理；检查数值条件与解的可重复性。
6. **加入交易摩擦**：成本随规模、波动、价差、参与率、可成交量、做空条件和交易时段变化；比较简单成本基线与更细冲击模型。
7. **滚动时间外验证**：按真实再平衡频率预测、优化、生成目标、模拟订单和更新账户；禁止未来资产池与全样本协方差。
8. **压力与参数稳定性**：对均值、协方差、交易成本、成交率、冲击和约束做场景扰动；报告最坏/分位表现、杠杆、集中度和换手。
9. **归因与放行**：分解市场/行业/风格/选股、现金、费用、融资、冲击与模型贡献；以净结果和风险限额决定是否进入模拟或小规模执行。

## 5. 组合验证应该回答什么

最低指标包括：年化几何收益、波动、最大回撤/恢复、下行风险、基准超额、跟踪误差、换手、集中度、参与率、成交覆盖、费用与冲击分解、可行性失败次数。按月份/年份、波动状态、行业、规模和流动性分层报告，避免总体平均掩盖尾部失败。

不确定性评估应尊重横截面与时间依赖。可采用按时间块或共同冲击单位重采样的情景分析，并将参数估计、组合选择和策略比较的多重选择计入；随机 bootstrap 逐行抽样通常破坏组合收益的时序结构。

最低对照矩阵：

| 对照 | 要隔离的问题 |
|---|---|
| 信号排序但不优化 vs 优化 | 优化步骤是否提供增量，而非信号本身 |
| 无成本 vs 成本后 | 收益是否被换手和冲击吃掉 |
| 收缩/稳健输入 vs 样本输入 | 增益来自更稳定估计还是参数偶然 |
| 约束组合 vs 无约束组合 | 约束改变了多少收益、风险和容量 |
| 真实成交/保守成交 vs 理想成交 | 执行假设是否是回测主因 |
| 训练期/验证期/锁定测试期 | 是否存在重复试验和样本外退化 |

## 6. A 股与美股专项实现

| 方面 | A 股 | 美股 |
|---|---|---|
| 可行域 | 普通股票常见的 T+1、涨跌幅约束、停复牌、板块/证券状态、交易单位等需逐证券和日期核对；现金、持仓和可卖数量分账 | 常规/延长时段、卖空 locate/borrow、交易场所、公司行动、ETF与个股规则影响可行仓位 |
| 价格与现金流 | 除权、分红、送转、停牌、退市和复牌处理须映射到账户账本；复权收益不能直接充作成交收益 | 拆并股、现金/股票分红、特别股息、退市、ADR与货币换算都需按持有单位与现金流处理 |
| 成本 | 费用结构、印花税/规费/佣金、价差、冲击、涨跌停无法成交和流动性分层按日期核实；封板不等于可执行成交 | 佣金/监管费用、价差、冲击、借券与融资、场所差异及盘前盘后流动性按账户和日期核实 |
| 基准和暴露 | 使用当时成分与行业分类；避免幸存者偏差；受制度限制的指数/风格暴露要真实建模 | 基准成分、分类版本和上市场所点时化；处理多股类、跨币种和国际收入暴露 |

这里不固化费率、交易规则或税费数字。它们会依账户、品种、场所和生效日期变化，回测需保存版本化费率表与可交易状态。

## 7. 放行与停用条件

**考虑放行**：模型相对透明基线在锁定时间外仍有增量；压力情景下约束可行；交易成本、成交限制、账户现金流完整；权重不由微小参数扰动主导；容量和持仓集中度可接受。

**暂停或回退基线**：样本外优势依赖极端均值估计；优化器频繁不可行；权重剧烈跳变；压力期风险预算失守；成本后收益被冲击抵消；账户账本无法复算；点时资产池缺失。
