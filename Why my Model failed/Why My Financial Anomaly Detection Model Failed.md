# 金融异常检测模型为何失效（Why My Financial Anomaly Detection Model Failed）

> **英文摘要（English summary）：** This report separates data-quality errors, unusual market events, risk anomalies, and trading anomalies. It compares robust statistics, PCA residuals, Isolation Forest, LOF, One-Class SVM, autoencoders, and change-point detection, then connects scores to thresholds, human review, and controlled actions. Anomaly scores are not forecasts or trading signals by themselves.

## 金融异常检测为什么会失败：从异常分数到可处置风险信号

异常检测的任务不是找出“看起来不寻常”的点，而是识别在指定信息集、市场状态和决策时点下，值得进一步调查或采取有边界动作的观测。**少见不等于错误，异常不等于可预测，更不等于可交易。**

本文涵盖统计距离、PCA 残差、Isolation Forest、LOF、One-Class SVM、自编码器和变化点检测，并区分数据质量告警、市场事件异常、风险异常与交易异常。下文是研究设计，不是基于某一真实账户或完整历史数据得出的实证结论。

## 1. 先定义“异常”与处置目标

必须先回答四个问题：

1. **对象是什么**：单笔成交、日线、证券横截面、盘口状态、账户行为，还是宏观/系统风险序列？
2. **异常相对什么基准**：同一证券的自身历史、同一时点的同业横截面、同一时段的盘口，还是条件分布？
3. **在何时识别**：收盘后复核、下一根 bar 决策，还是盘中告警？
4. **告警后做什么**：检查数据、降低模型置信度、限制新开仓、进入人工复核，还是仅记录？

把异常类型拆开，避免把不同问题塞给同一模型：

| 类型 | 例子 | 首要处理方式 |
|---|---|---|
| 数据异常 | 复权错误、重复行情、错误时区、供应商缺值 | 数据质量隔离与回补 |
| 点异常 | 某证券当日收益/成交量显著偏离条件分布 | 核对事件、流动性与报价 |
| 上下文异常 | 某波动在高波动状态正常、低波动状态异常 | 条件模型或状态条件阈值 |
| 群体异常 | 多证券同步偏离、行业内相关结构突变 | 横截面/系统风险分析 |
| 序列异常 | 方差、相关性或残差结构持续改变 | 变化点、状态切换、再估计 |
| 交易异常 | 报价陈旧、价差/冲击急升、拒单或成交断层 | 执行风控和交易暂停条件 |

一次市场冲击可以是真实而稀有的事件；把它当作脏数据删除，会抹掉最重要的尾部风险。相反，供应商坏点也不能被模型解释成 alpha。

## 2. 不同模型实际检测什么

| 方法 | 分数含义 | 主要假设与常见失效 |
|---|---|---|
| Robust z-score / MAD | 单变量相对稳健中心的偏离 | 未建模条件异方差、季节性或行业基准；固定阈值漂移 |
| Mahalanobis 距离 | 相对均值和协方差椭球的联合偏离 | 协方差病态、重尾、污染；普通样本协方差会被异常点带偏 |
| PCA / 因子重构残差 | 公共低维结构无法解释的部分 | 因子载荷或训练窗漂移；把真实新因子当噪声；全样本拟合泄漏 |
| Isolation Forest | 随机切分下容易被隔离的观测 | 分数受特征缩放、样本密度、采样和 `contamination` 影响；不识别时间因果 |
| LOF | 局部密度相对邻域的稀疏程度 | 高维距离失真、邻域跨制度、实时预测与训练分布错位 |
| One-Class SVM | 相对核边界的支持域偏离 | 核、尺度与 `nu` 敏感；大样本计算量和边界漂移 |
| 自编码器 | 对训练分布的重构误差 | 高容量模型也能重构异常；重构误差不等于异常概率 |
| 变化点 / CUSUM / 状态空间 | 参数或状态序列持续改变 | 误把单点跳跃当永久变化；多重扫描抬高误报；检测有延迟 |

Isolation Forest 的随机隔离机制源于原始方法论文；在金融时间序列上，PCA 与神经网络也被用于异常定位。它们说明的是可用方法，并不证明某一分数在 A 股或美股具有稳定收益预测能力。[Isolation Forest 原始论文](https://doi.org/10.1109/ICDM.2008.17)；[金融时间序列异常检测研究](https://arxiv.org/abs/2209.11686)

## 3. 失效机制：为什么分数很“漂亮”仍无用

### 3.1 训练集被污染，或“正常”被定义成幸存者

无监督方法没有天然干净的正例。若训练窗包含危机、数据故障和新制度切换，模型可能把它们一起学成正常；若只保留今天的存续证券，历史训练分布还会产生幸存者偏差。应记录训练时点、证券池版本、数据修订状态和事件剔除规则。

### 3.2 用全样本归一化、降维或调阈值

先对全历史做标准化、PCA、缺失值插补、分位数变换，再切分时间，会将未来均值、方差和结构写进过去。即便模型本身无监督，也会泄漏。所有变换、基准分布与阈值只能由当时的训练窗估计。

### 3.3 横截面把不同制度混为一谈

把小盘股和大盘股、低流动性和高流动性、常规交易和集合竞价、不同波动率状态的观测放进一个全局邻域，距离和密度就失去解释。分组太细又会令局部样本不足。基准应由任务决定，并做分层与合并敏感性分析。

### 3.4 阈值与“异常比例”被硬编码

把 `contamination=1%` 当成真实世界恰有 1% 异常，是把算法参数误当作先验事实。固定的历史分位数阈值可能在波动聚集期每天报警，也可能在制度突变时完全失灵。需要明确告警预算、误报代价、漏报代价、阈值更新规则和人工复核容量。

### 3.5 把事后标签当在线识别能力

调查确认的操纵、财务更正、退市和交易所处分往往延迟很久。用最终标签回填历史后，再用当时并不可见的字段训练，会高估及时检出率。标签必须有“事件发生、公开、系统取得、人工确认”时间；报告延迟分布和成熟样本范围。

### 3.6 从检测跳到交易决策

异常分数本身没有方向，也不表示未来收益为负。它可以触发审查或限制新风险，但任何交易动作都要另行验证净收益、风险改善、错失机会、冲击成本和误报后果。若用于仓位缩放，应测试分数是否在样本外增量改善组合效用，而不是只比较异常分类指标。

## 4. 可复核的端到端研究流程（pipeline）

1. **写清目标与动作**：确定异常类型、决策频率、告警延迟上限、调查预算、错误代价和动作权限。
2. **冻结可得信息集**：保存原始值、修订版、时间戳、证券身份、交易状态、行情来源及公司行为记录；建立点时证券池（point-in-time universe）。
3. **定义条件参照系**：选择自身历史、行业/规模/流动性分层或市场状态基准，事前规定异常事件的纳入与隔离规则。
4. **建立简单基线**：先比较规则阈值、滚动 MAD、稳健协方差或单变量控制图，再引入 IF、LOF、One-Class SVM、自编码器或变化点模型。
5. **时间顺序训练**：每个窗口只用当时可见数据拟合插补、缩放、PCA、模型和阈值。无监督模型也需要严格的时间边界。
6. **阈值分层**：按告警用途设候选阈值；以训练/验证区间确定，并在最终时间外测试前冻结。阈值漂移要作为模型状态变化监控。
7. **多层评估**：分别报告技术识别、调查价值和经济/风险价值，不用一个 AUC 代替三者。
8. **稳健性与事件复盘**：检查不同窗口、随机种子、特征子集、市场状态和证券组的稳定性；逐条查看高分、低分及漏报事件。
9. **上线分阶段**：先影子告警、再人工复核、最后在明确限额内触发可逆动作；保留静默模式、回滚和事件日志。

## 5. 评价指标与校验设计

有成熟标签时，报告精确率、召回率、PR-AUC、每千笔/每交易日告警数、发现延迟、分组误报率以及阈值敏感性。类极不平衡时，ROC-AUC 可能掩盖告警队列质量。概率校准只适用于输出能解释为概率且标签定义清晰的模型。

缺少可靠标签时：

- **人工复核抽样**：对高分、阈值附近和随机低分样本分层抽查，估计发现率与误报率；记录审核员一致性和标签成熟日期。
- **合成注入**：注入已知幅度、持续期、相关结构的异常，比较检出概率和延迟。注入只能检验受控扰动，不能替代真实市场外部有效性。
- **稳定性审查**：比较每期告警率、分数分布、特征贡献和证券组；告警稳定并不等于识别正确，骤变也不自动说明失效。
- **处置价值**：若分数用于交易风险，按真实成交和账户账本计算成本后结果，同时列出正常行情下误拦截的机会成本。

Bootstrap 应按日期、事件或证券群组等依赖单位设计，不能把高度相关的逐行观测当成独立样本。变化点检测还应单独报告检测延迟与误报频率。

## 6. A 股与美股的专项核查

| 环节 | A 股 | 美股 |
|---|---|---|
| 证券与事件 | 新股上市阶段、风险警示证券、停复牌、涨跌幅限制、公司行为和历史证券状态均会改变分布；不能将不可交易日直接标成异常收益 | 拆并股、特别股息、退市、上市地变化、盘前盘后、交易暂停及公司公告时点会制造结构差异 |
| 成交与价格 | 需要保存集合竞价/连续竞价时段、涨跌停封单、停牌、T+1 等证券/日期适用约束；“触及价格边界”不等于行情错误，也不保证可以成交 | 需要区分常规与延长时段、报价更新和成交、交易暂停、卖空可借性及场所差异；盘前盘后流动性不能按常规时段等同处理 |
| 横截面参照 | 行业、规模、流动性、板块制度和上市阶段分组需要版本化，避免当前分类回填历史 | 行业分类、上市交易场所、ADR/普通股、ETF/个股、常规时段与延长时段需采用一致且可追溯的参照组 |
| 运营处置 | 异常分数优先分流到数据核对/风险复核；任何限仓规则要映射到交易和账户约束 | 将告警映射到市场数据监控、订单控制和风控流程；不能把模型高分当作自动卖空或强平指令 |

以上是研究检查项，不是固定规则清单。交易时段、证券状态、费用和交易约束随品种、场所及生效日期变化，落地时必须绑定适用版本。

## 7. 放行条件与停用条件

**可进入下一阶段**：分数有明确含义；时间边界无泄漏；人工审查发现率/误报率可量化；阈值和告警预算有依据；相较简单基线具增量价值；下游动作有权限、限额、日志与回滚。

**应暂停或降级**：点时数据无法重建；分数只在全样本预处理后有效；标签时间不清；告警率随状态失控；输出主要识别停牌/复权/流动性差异而非目标风险；触发动作的样本外净收益或风险效用不可复现。
