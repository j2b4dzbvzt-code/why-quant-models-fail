# 金融重采样方法为何失效（Why My Resampling Failed）

> **英文摘要（English summary）：** Resampling quantifies uncertainty only when the resampling unit and dependence structure match the question. IID bootstrap and random cross-validation often fail for financial panels because dates, securities, events, labels, and portfolios are dependent. This report distinguishes predictive validation from uncertainty estimation, derives the basic bootstrap intuition, compares block and grouped schemes, and provides a nested walk-forward workflow for A-share and U.S. equity research. Repeated resamples cannot create unseen regimes or repair biased data.

**案例等级**：统计方法说明，不报告真实市场的区间估计或策略结果。

## 1. 先问要估计哪一种不确定性

重采样（resampling）不是一个单一算法。常见用途至少有：

1. **预测泛化误差**：模型在下一段时间会怎样表现；
2. **参数不确定性**：同一估计程序换一批有效样本时，参数会如何变化；
3. **模型选择不确定性**：特征、超参数或候选模型的选择会否改变；
4. **策略路径风险**：收益序列的回撤、尾部损失和破产风险；
5. **抽样设计的不确定性**：日期、事件或证券群体的变化造成多大波动。

滚动/扩展窗时间验证主要模拟未来顺序运行；bootstrap 主要在假设某种抽样机制后近似统计量的抽样分布。二者不能互相替代。若研究问题是“下一制度期能否泛化”，普通 bootstrap 区间并不是直接答案。

## 2. IID Bootstrap 的含义与边界

有 \(n\) 个 IID 抽样单位 \(Z_1,\ldots,Z_n\) 时，非参数 bootstrap 每次从这 \(n\) 个单位中有放回抽取 \(n\) 个，重算统计量 \(T^*\)。重复 \(B\) 次后，\(T^*\) 的经验分布近似统计量在相同总体抽样机制下的波动。

每个原始单位一次都未抽中的概率为 \((1-1/n)^n\)，大样本下趋近 \(e^{-1}\)；因此一次重采样中期望的不同单位比例趋近 \(1-e^{-1}\)。这是有放回抽样的组合结果，不证明样本有代表性，也不证明时间序列适用 IID 假设。

Bootstrap 标准误只反映重采样机制下的变动，不能自动消除偏差、幸存者偏差、数据挖掘、遗漏变量、结构断点或目标错设。增加复制次数 \(B\) 只会减少模拟误差，并不会增加独立历史信息。

## 3. 金融数据为何违反朴素重采样假设

### 3.1 日期、证券和事件存在依赖

同一天大量股票共同承受市场冲击；单一公司跨日收益存在自相关；同一财报、并购、政策或诉讼事件会生成多条重复观测。随机抽行可能把同一依赖簇同时放进训练与测试。

### 3.2 标签区间重叠

若每天生成未来 20 日收益标签，相邻决策日共享大部分未来回报。随机 CV 会让训练集和测试集拥有几乎相同的结果区间，模型或阈值选择因此过度乐观。切分应使用每条样本的真实信息区间做 purging；对仍存在的短期依赖，才按设计加入 embargo。

### 3.3 非平稳和结构断点

把不同政策、波动、流动性和市场制度时期的观测当作可交换单位，会将未来不一定重复的状态平均混合。历史中没有的危机不会因重复抽取现有样本而出现。若目标是估计“已观察制度下的条件不确定性”，应明确这一窄口径；若目标是下一状态，需额外的压力情景和制度假设。

## 4. 选择与目标一致的方案

| 方法 | 主要用途 | 需要的假设/限制 |
|---|---|---|
| 前向/扩展窗验证（walk-forward） | 近似部署时序，评价未来预测 | 历史窗口、再训练频率需与实际一致；数量有限时区间较宽 |
| 按日期/事件分组的切分 | 防止共同冲击或同一事件跨折 | 群组需代表实际依赖单位；小群组数仍限制推断 |
| 移动区块 Bootstrap（moving block） | 保留固定长度区块内局部时间顺序 | 块长决定依赖保留与有效独立块数量之间的权衡 |
| 平稳 Bootstrap（stationary bootstrap） | 使用随机长度连续区块 | 仍假设某种局部稳定，不适合任意结构变化 |
| 残差 Bootstrap | 在正确模型下重采样误差 | 残差机制须与同方差、独立或所建依赖结构相容 |
| 聚类 Bootstrap（cluster bootstrap） | 按发行人、日期或事件群组抽样 | 群组数量和群内相关必须明确；多向依赖需要更谨慎设计 |
| 策略路径 Bootstrap | 估计收益路径/回撤分布 | 必须保留时间依赖、仓位连续性、未成交和现金流规则 |

块长不能只靠让区间变窄来选。应报告多个合理块长、有效区块数和结果变化；块太短会破坏依赖，块太长则留下极少的不同区块。

## 5. 置信区间不等于安全边界

标准误、百分位区间、偏差校正加速区间（BCa）、学生化区间等方法各有适用条件。选择方法不能替代检验抽样单位与总体假设。对最大回撤、极端分位数、破产概率和最差事件，普通百分位 bootstrap 可能因样本没包含相似尾部路径而严重失准。

模型选择的不确定性也不能在最终胜出模型上单独重采样后忽略。若要估计完整研究流程的变动，每个复制内应重做特征筛选、模型选择、调参、校准和阈值选择，并报告选中规格频率；这仍不能修复在全样本提前做过的筛选。

对序列相关收益而言，直接对单日收益随机洗牌会改变回撤路径和波动聚集。策略路径抽样还应保留换仓、持仓重叠、现金余额、拒单和持有期等账本状态。

## 6. 验证结论的双层流程

1. 定义待量化的对象：泛化误差、参数、模型选择、极端损失或策略路径。
2. 确定独立信息单位：决策日期、事件、证券实体、时间区块或已经完成的账户路径。
3. 先冻结点时样本与标签区间；解决证券映射、缺失语义、重叠结果、停牌和退市覆盖。
4. 外层按部署时间顺序切分；同日股票整组处理，训练标签须在测试决策前成熟。
5. 内层只在外层训练期内进行特征选择、调参、校准和阈值决策；所有预处理逐折拟合。
6. 对外层时间外预测作日期/制度分段报告，不把数千个同日证券行当成数千份独立证据。
7. 若需要区间，再对匹配的问题单位进行分组或区块重采样；每次复制重算目标统计量。
8. 报告区间对块长、样本起点、事件定义、模型搜索过程及种子的敏感度，并与未重采样的时间外结果并列。

只有在事前定义的目标和方案下，重采样分布才具有可解释性；看到区间后再选择块长、指标或策略，会引入新的选择偏差。

## 7. A 股与美股重采样审计

- **A 股**：区块邻接应按交易日而非自然日定义；长假期间不是连续交易观测。保留同日市场/行业冲击、停复牌、涨跌限制、公司行动和无法退出的仓位。
- **美股**：明确常规时段与延长时段、隔夜间隔、场所与事件跳空；保留退市、股类、ADR、借券和未成交信息。
- **跨市场**：先按信息可得时间和决策时钟对齐，不是只按日期标签拼接；处理时区、夏令时、节假日和货币转换。
- **两边共同**：说明结论是条件于已观察制度，还是尝试外推到更广未来分布。任何重采样都不能从缺失历史中推导出无假设的结构断点风险。

## 8. 报告模板与停止规则

至少记录：问题对象、抽样单位、时间折、purging/embargo 规则、区块/群组定义、块长与敏感性、复制数、随机种子、有效日期/群组数、是否在复制内重做模型选择、区间类型、统计量定义和未重采样时间外结果。

当独立事件/区块过少、结论随合理块长翻转、单一危机支配全部重采样，或验证折不符合真实部署顺序时，应降低证据等级。窄置信区间可能只是对同一批少数制度的重复抽取。
