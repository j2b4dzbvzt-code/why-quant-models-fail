# 金融因果推断模型为何失效（Why My Causal Inference Model Failed）

> **英文摘要（English summary）：** This report covers event studies, difference-in-differences, instrumental variables, synthetic controls, matching/weighting, regression discontinuity, and heterogeneous effects. It starts from the estimand and identification assumptions, then examines timing errors, post-treatment controls, staggered treatment, spillovers, and market-specific inference. Prediction accuracy is not causal evidence.

## 金融因果推断为什么会失败：从相关性、识别假设到可迁移结论

因果推断不是给回归加上更多控制变量，也不是把预测准确率换成一个系数。它要回答：**对明确对象施加明确干预，相对于某个反事实，目标结果会怎样变化？**如果干预、对象、时间、结果或反事实说不清，模型再复杂也不能自动给出因果结论。

本文覆盖事件研究、双重差分（DID）、工具变量（IV）、合成控制、匹配/加权、断点设计和异质性效应。所有市场示例用于研究设计，不代表某个交易事件已被证明具有因果效果。

## 1. 先定义估计对象，而不是先选回归式

设 (Y_i(1)) 是对象 (i) 接受处理时的潜在结果，(Y_i(0)) 是未接受处理时的潜在结果。因果效应涉及不可同时观测的反事实。研究方案至少要预先写清：

- **处理**：政策、规则变更、指数纳入、公司行动、信息发布，或投资组合/交易策略干预？处理强度、开始日期、预期和实际暴露如何定义？
- **对象与单位**：公司、证券、交易日、账户、投资者还是行业？结果在哪个单位观测？
- **结果与期限**：收益、成交量、流动性、波动率、融资约束、公司投资，还是策略净收益？短期公告反应和长期经营影响不是同一个估计对象。
- **因果参数**：平均处理效应、已处理组效应、组别-时间效应、边际效应、局部平均处理效应，还是动态路径？
- **干预机制**：谁受影响、谁作为对照、信息如何传导、是否存在预期反应和溢出？

若问题实际上是“明天哪些股票收益更高”，那是预测问题；若问题是“某制度变化导致了什么结果”，才是因果识别。预测特征重要性、SHAP 排名和高相关系数都不是因果效应。

## 2. 设计与方法的识别假设

| 设计 | 识别思路 | 不可省略的检查 |
|---|---|---|
| 事件研究 | 事件窗口内异常结果相对反事实基准 | 事件时点无污染、预期形成、并发事件、基准模型、窗口选择与重叠事件 |
| DID | 处理组与对照组结果变化差异 | 无处理时平行趋势、无预期、组间无干扰、处理与对照构造、异质处理效应 |
| IV | 工具变量改变处理而不直接改变结果 | 相关性、排除限制、独立性、单调性（若解释 LATE）；弱工具和聚类推断 |
| 合成控制 | 加权供体组合近似处理单位的处理前路径 | 供体池无污染、处理前拟合、供体权重、处理后差异的安慰剂和敏感性 |
| 匹配/倾向得分/双重稳健 | 观测协变量条件下可比或依赖双重模型保护 | 无未观测混杂、重叠性、平衡、极端权重、协变量是否先于处理 |
| 回归断点 | 阈值附近近似随机的处理分配 | 阈值不可操纵、连续性、带宽、函数阶数、阈值两侧协变量连续 |

**统计显著不修复识别失败。**较窄置信区间不能补救一个错误的对照组；更复杂的模型也不能让不可检验的排除限制自动成立。

## 3. 最常见的逻辑错误

### 3.1 事后挑选事件、窗口、对照和结果

对同一事件测试大量公告定义、窗口、基准、子组和收益口径，最后报告最显著的一种，会引入研究者自由度。应登记全部方案族、主要终点、分析窗口和排除规则；未预注册的探索结果应标注为探索并做多重检验/选择偏差讨论。

### 3.2 把公告时间、事件时间、处理时间混成一个时间戳

财报期末不等于公开时间，公告发布不等于所有交易者收到信息，政策通过不等于生效，指数公告也不等于纳入生效。按真正的信息可得时刻构造暴露，并处理盘中、盘后、节假日和时区。

### 3.3 控制了处理后的变量

处理后的成交量、融资、波动率或价格反应可能是中介变量。把它们当普通控制变量会截断总效应、引入碰撞偏差，或改变估计目标。用因果图标注变量角色，区分基线混杂因素、中介、结果和碰撞变量。

### 3.4 把“前趋势不显著”当成平行趋势证明

前趋势检验功效可能很低，未拒绝零不代表趋势相同。应报告效应量与区间、事件前动态路径、经济可容忍的偏差范围，并进行敏感性界限或替代设计。事件研究图不能单独证实平行趋势。

### 3.5 交错处理下机械使用 TWFE

当处理时点不同且效应随组或时间异质时，传统双向固定效应可能把已处理组当作其他组的对照，并形成难以解释甚至负权重的组合。先定义目标参数，再选能识别该参数的组别-时间估计与聚合方式；不能只因软件默认 TWFE 就沿用。[交错 DID 估计的权重与异质性问题](https://www.sciencedirect.com/science/article/pii/S0304407621001445)；[多期 DID 的组别-时间效应方法](https://www.sciencedirect.com/science/article/pii/S0304407620303948)

### 3.6 忽略溢出、干扰与一般均衡

一个公司被纳入指数会影响同业、相关 ETF、供需和对照证券价格；市场政策也可能影响整个市场。此时 SUTVA/无干扰不成立。考虑暴露强度、网络、相邻证券、供体污染和一般均衡反馈，必要时把估计目标改为直接效应/溢出效应。

### 3.7 把日度面板行数误作独立样本数

公司内时间相关、共同市场冲击和行业共振会让普通标准误过小。聚类层级需要对应处理分配和依赖结构；时间维度短、聚类数少时，常规聚类渐近近似也可能差。说明推断单位并做适当的小样本或随机化推断敏感性分析。

## 4. 因果研究完整研究流程（pipeline）

1. **预注册研究问题**：确定处理、对象、结果、反事实、目标参数、方向/期限和主要比较。
2. **绘制因果结构**：列出混杂因素、处理前预测因子、中介、选择变量、共同冲击和可能的溢出，检查控制集。
3. **建立事件/处理账本**：版本化来源、精确发生/公告/可得/生效时间、受影响集合、预期形成和并发事件。
4. **构造点时面板（point-in-time panel）**：证券身份、上市/退市、行业、公司行为、处理暴露和财务变量使用当时可见版本；处理停牌与不可交易结果，但不事后删除困难样本。
5. **选择识别设计**：基于分配机制与反事实可信度选 DID、IV、合成控制、断点或事件研究；写出估计式、目标参数和明确假设。
6. **先展示设计诊断**：处理前趋势/拟合、协变量平衡、重叠性、工具第一阶段、供体权重、阈值密度和潜在污染。
7. **推断与敏感性**：选依赖结构匹配的标准误；做安慰剂日期/对象、窗口、对照、权重、带宽和未观测混杂敏感性。
8. **多重研究校正**：披露试验家族和筛选过程；若目标为策略应用，另做严格时间外检验，不把因果样本的拟合当未来可交易证据。
9. **报告可迁移边界**：报告对象、时间、市场制度、估计参数、置信区间、识别假设和失效条件；不要将局部效应外推为全市场规律。

## 5. A 股与美股的专项核查

| 研究环节 | A 股 | 美股 |
|---|---|---|
| 处理与生效 | 政策试点、板块制度、指数调整、监管口径与发行制度可能分批实施；公告、发布、生效与实际覆盖需要分开记时 | SEC/公司披露、交易所规则、指数公告、公司行动与实际生效时点需区分；盘前/盘后发布影响可交易窗口 |
| 结果观测 | 涨跌幅约束、停复牌、T+1、交易时段和证券状态可能截断/延迟观察到的价格反应；需明确是潜在价值反应还是可成交收益 | 交易暂停、场所分散、延长时段、卖空可得性和公司行动会影响结果与对照可比性 |
| 对照设计 | 板块、行业、规模、流动性和政策暴露常同时变化；当前标签回填历史可能改变处理组 | 上市场所、ADR/普通股、ETF持仓、行业、机构持有及披露质量可能影响处理/对照差异 |
| 外推 | 制度边界、投资者结构与流动性差异可能限制从一个板块或政策批次外推至全市场 | 市场微观结构、公司治理、交易场所和借券机制限制跨股票、跨时期外推 |

规则或政策变化如果分批落地，特别检查处理时间异质性；交易限制或价格边界若影响实现收益，必须把识别出的结果效应与可执行交易收益分别报告。具体制度应按目标证券、场所和日期核验。

## 6. 结论报告的最低标准

一份可审查的因果结论至少应包含：估计对象与目标参数；处理分配机制；识别假设及可检验后果；处理/对照和时间构造；主估计与不确定性；关键诊断与敏感性；全部主要规格族；市场范围和外推边界。若关键假设不可验证，应明确这属于识别限制，而不是把结论写成“已证明”。
