## 1. 什么叫“可信”：正确性、可执行性和统计证据

回测可信度至少有五层：

1. **数据可信**：证券、时间、价格、公司行为、基本面和行情状态代表当时可见事实，而非今天修订后的历史。
2. **逻辑可信**：信号、标签、模型、仓位和交易规则按研究卡运行，没有多算、漏算或暗中修改。
3. **执行可信**：信号形成后确有机会下单；模拟成交与订单信息、场所、容量、状态、成本和账户约束相容。
4. **统计可信**：切分尊重时间依赖和重叠标签；试验数量、非正态、序列相关和小样本不确定性均披露。
5. **经济可信**：成本后收益、风险、容量、极端亏损和资本占用支持真实组合决策。

这些层有先后关系。数据或账本错误时，再高的DSR也只是精确计算了错误结果；成交不可实现时，正确的OOS分类器也不能转成实际收益。可信度是一组证据，不是单独一个分数。

### 1.1 研究、历史模拟、情景评估不可混为一谈

第11章警示：回测可做sanity check，但不是因果实验。若反复“查看结果—改规则—再查看结果”，测试集已参与研究。

实务上分三阶段：

- **机制研究**：提出可证伪解释，用点时变量、事件研究、简单统计和反事实验证机制。
- **策略模拟**：冻结逻辑后，模拟信号如何形成订单、成交和持仓，检查收益及可执行性。
- **筛选/部署证据**：披露完整试验数，用多路径评估、前向验证和纸面交易判断策略能否承受选择偏差与现实执行。

显性参数搜索只是研究尝试的一部分；手工调整股票池、成本、起止日期或展示指标，也会消耗测试信息。

## 2. 七类经典偏差与扩展审计

第11章（印刷页151—160）列举幸存者、前视、事后讲故事、数据挖掘/窥探、交易成本、异常值和做空风险。每项都应给可复算的检查证据。

### 2.1 幸存者与证券身份偏差

只用今天仍上市公司，会删除退市、破产、并购换股和长期停牌证券，也会漏掉退市前回报与风险状态。按稳定实体ID、listing ID、ticker有效区间、上市/退市日期、状态和交易所版本维护主表。每日选股从当时可投资集开始，指数/行业成员及融资融券状态用点时快照。“仅存活样本”可作偏差诊断，不作正式结果。

### 2.2 前视、时间对齐与数据回填

事实发生、首次公开、供应商接收和策略真正可读取的时间要分开。财报所属季度不是可知时间；宏观初值与修订值也不是同一版本。默认只使用`available_at < t`的数据；时间戳相等时，只有可靠序号能证明数据先于决策，才允许纳入。公告精度只有日期、盘后发布或供应商回填时，采取保守准入。

若收盘价用于生成信号，就不能默认以同一收盘价成交，除非订单实际在收盘竞价前生成且符合规则。建议写时序断言：

~~~python
assert (features["available_at"] < features["decision_time"]).all()
assert (orders["signal_time"] <= orders["submit_time"]).all()
assert (fills["submit_time"] <= fills["fill_time"]).all()
~~~

断言以统一时区、版本明确的时间戳为前提。把两个无时区时间戳直接比较不构成审计。

### 2.3 标签重叠与交叉验证泄漏

金融观测通常非IID：收益自相关、波动聚集、持有期标签重叠，同一市场冲击会同时影响多只股票。第7章指出，特征相似本身不一定泄漏；关键是训练标签与测试标签是否共享信息，或测试信息是否进入训练。

随机K-fold会将相邻/重叠事件拆到训练和测试，训练过程可能间接看到测试事件结果。即使标签不重叠，全样本拟合预处理、同一发行人多条事件、共同因子、长记忆特征也会泄漏。

### 2.4 选择偏差、多重尝试与故事化

试验账本覆盖特征、标签、持有期、止盈止损、仓位映射、风险限制、样本区间、市场、股票池、基准、成本口径、异常处理和所有被查看指标。候选之间高度相关时，原始试验数不等于独立试验数；DSR/PBO需说明有效试验数假设，不可随意缩小N美化结果。

### 2.5 成本、冲击与容量偏差

分拆佣金/规费/税费、价差、市场冲击、延迟与机会成本、融资利息、借券费、分红补偿和换汇。费率按方向、规模、市场状态、场所、账户和日期配置。

常见平方根冲击近似：

\[
\text{Impact} \approx Y\,\sigma\,\sqrt{Q/V}
\]

Q为订单规模，V为执行窗口内可执行成交量，σ为匹配窗口波动率，Y须用执行数据校准。它不是普遍定律；小票、跳空、拥挤事件、盘口稀疏、价格限制或参与率很高时容易低估尾部成本。

绘制AUM从小到大时的净收益、换手、成交率、风险和冲击曲线。固定bps成本不能证明容量。

### 2.6 异常值、幸存赢家和隐藏集中度

极端收益可能是数据错误、并购对价、拆股错位、触板后跳空、少数高风险赌注或真实收益。依次回看原始成交/公司行为、对照独立来源、按交易/标的/日期/模块/状态归因，检查去掉最大1、5、10笔或月份的结果。剔除极端值仅作诊断，保留原始主结果。正负收益、月份、交易和标的均报告集中度。

### 2.7 做空、市场状态和订单可成交性

负信号不代表可卖空。记录账户许可、点时券源、借券费、召回、卖空标记/价格测试、保证金、强平和空头分红补偿。缺历史借券数据时，限定为空头未验证假设、作长-only对照或悲观情景。

触及涨跌幅、LULD价格带、停牌、竞价、盘前盘后和熔断都会改变成交概率。触价不等于成交；日线bar不能复原精确排队位置。

## 3. 时间验证：Purging、Embargo、Walk-forward、CPCV

### 3.1 Purging处理事件区间重叠

样本i的标签使用区间 \([s_i,e_i]\)，样本j使用 \([s_j,e_j]\)。若：

\[
[s_i,e_i]\cap[s_j,e_j]\neq\varnothing
\]

训练标签与测试标签就共享底层随机变化。Purging删除与测试标签信息区间重叠的训练样本。核心是保存真实标签终点，不是盲目按行号删除固定间隔。固定gap仅在采样和持有期稳定、且确实覆盖依赖时有意义。

### 3.2 Embargo补充短期依赖，不是魔法常数

当CV允许测试段之后的样本进入训练时，测试事件之后紧邻的训练观测可能有串联依赖。Embargo从测试事件尾部继续屏蔽一段训练数据。长度依据特征记忆、样本频率、标签跨度和相关衰减，并对不同长度作敏感性分析。

Embargo不能修复测试集反复窥视、全样本拟合变换、同发行人/共同冲击跨折、结构突变、未标记事件依赖或真实前向部署问题。

### 3.3 Purged splitter教学代码

以下代码以整数时间位置表示标签区间，针对给定train/test索引清理重叠。它不是完整sklearn兼容的CPCV；生产代码还需支持多证券日历、发行人分组、缺失区间和更完整的信息窗口。

~~~python
import numpy as np

def purge_train_indices(train_idx, test_idx, label_start, label_end,
                        embargo_bars=0):
    """
    label_start / label_end 是一维整数数组，每个样本标签区间的
    首末时间位置，两端均包含。
    """
    if (not isinstance(embargo_bars, (int, np.integer))
            or isinstance(embargo_bars, (bool, np.bool_)) or embargo_bars < 0):
        raise ValueError("embargo_bars must be a non-negative integer")
    label_start = np.asarray(label_start)
    label_end = np.asarray(label_end)
    if (label_start.ndim != 1 or label_end.ndim != 1
            or label_start.size != label_end.size
            or not np.issubdtype(label_start.dtype, np.integer)
            or not np.issubdtype(label_end.dtype, np.integer)):
        raise ValueError("label_start and label_end must be equal-length integer arrays")
    if (label_end < label_start).any():
        raise ValueError("each label interval must satisfy start <= end")
    n_samples = label_start.size
    train_idx = np.asarray(train_idx)
    test_idx = np.asarray(test_idx)
    for name, values in (("train_idx", train_idx), ("test_idx", test_idx)):
        if values.ndim != 1 or not np.issubdtype(values.dtype, np.integer):
            raise ValueError(f"{name} must be a one-dimensional integer array")
        if values.size and ((values < 0).any() or (values >= n_samples).any()):
            raise ValueError(f"{name} contains an out-of-range sample position")
        if np.unique(values).size != values.size:
            raise ValueError(f"{name} must not contain duplicate positions")
    if test_idx.size == 0:
        raise ValueError("test_idx must contain at least one position")
    if np.intersect1d(train_idx, test_idx).size:
        raise ValueError("train_idx and test_idx must be disjoint")
    keep = np.ones(train_idx.size, dtype=bool)
    test_intervals = [
        (int(label_start[j]), int(label_end[j])) for j in test_idx
    ]

    for k, i in enumerate(train_idx):
        a, b = int(label_start[i]), int(label_end[i])
        overlaps = any(a <= test_b and b >= test_a
                       for test_a, test_b in test_intervals)
        embargoed = any(
            test_b < a <= test_b + embargo_bars
            for _, test_b in test_intervals
        )
        keep[k] = not (overlaps or embargoed)

    return train_idx[keep]
~~~

给splitter写属性测试：训练/测试标签区间无交集，embargo后训练点距离正确，索引完整且不重复，X/y/标签终点对齐。示例按测试标签终点附近屏蔽，不会自动判断全部特征窗口共享；需按策略扩展信息区间或实体分组。

### 3.4 Walk-forward的用途与不足

WF每个决策只使用当时以前数据，最适合回答“按当时系统顺序运行会怎样”，容易与纸面交易核对。预先定义扩展窗/滚动窗、重训练频率、暖机期和冷启动处理。

WF仍可能被过拟合：研究者不断改规则直到单一路径好看；早期决策训练较少；特定危机/牛市顺序可能支配结果。WF不天然免于选择偏差，仍需记录所有调参轮次并做前向锁定评估。

### 3.5 CPCV的路径解释和边界

将T个时间顺序样本分成N个连续组，每次选k组测试、其余训练，purge/embargo后重训，拼接各组合OOS预测为多条路径：

\[
\phi[N,k]=\frac{k}{N}\binom{N}{k}=\binom{N-1}{k-1}
\]

N=6、k=2时有15个测试组合，可拼成5条路径。增大k会降低训练比例但增加路径数；不可只为增加路径选参数。

CPCV训练可能用到测试期之后数据，因此不是历史实时表现。路径相互依赖，不能当独立重复样本。必须报告分组、k/N、训练比例、覆盖、purge/embargo、拼接方式和路径相关性；反复改CPCV设计也会过拟合。

### 3.6 PBO/CSCV诊断“选冠军后掉队”

给定N个候选策略收益面板，将S个连续时间块（S为偶数）作对称IS/OOS组合。每次选IS表现最佳策略，再看该策略OOS排名分位 \(\omega\in(0,1)\)：

\[
\lambda=\log\left(\frac{\omega}{1-\omega}\right),\qquad
PBO\approx\Pr(\lambda<0)
\]

即IS冠军在OOS低于中位数的频率。高PBO提示选优退化风险，不意味着某策略必然失败；低PBO也不证明点时数据或成交真实。

CSCV/PBO以固定候选收益矩阵诊断选择；CPCV通常在每个训练折重估模型并构造路径。两者不可混称，候选收益必须同日期、基准和口径。

## 4. 超参数搜索和嵌套验证

第9章介绍GridSearchCV、RandomizedSearchCV、对数均匀抽样和log loss。实务补充：

1. 网格、随机、贝叶斯搜索都消耗试验预算；随机搜索节省计算，不消除选择偏差。
2. 内层验证折选参数，外层测试折评估整个选型流程。
3. 标准化、填补、裁剪、降维、特征选择、样本权重、校准和阈值都要在训练折估计。分类评分不等于策略净回报。

~~~text
外层折：留出当前未参与选型的区段
  内层purged folds：
    在训练折拟合变换、特征选择、模型和校准
    用预设评分与约束选择参数
  用完整outer-train重拟合
  对outer-test只预测一次
拼接所有outer OOS预测与成交账本
~~~

看过outer OOS后若改动任何内容，它就成为开发数据。模型预测层与策略经济层同时评估。

| 问题 | 指标示例 | 不能单独推出 |
|---|---|---|
| 标签分类 | balanced accuracy、MCC、Precision/Recall/F1 | 不等于成本后收益 |
| 概率质量 | log loss、Brier、校准曲线 | 不等于真实赔率或合适仓位 |
| 排序能力 | Rank IC、分层收益、top-bottom spread | 不等于相应规模可成交 |
| 交易表现 | 净PnL、风险调整表现、回撤、成本覆盖、容量 | 不等于统计确定性 |
| 执行质量 | Implementation shortfall、成交率、滑点、参与率 | 不等于信号有预测力 |

负log loss用于重视概率置信度的预测评分，不代表它自动带来最高投资收益。

## 5. 合成数据：指定机制的实验室

第13章用OU过程说明均值回复速度、长期均衡、噪声、止盈止损和最大持有期如何改变交易规则。其价值是在已知生成机制下分析规则，不把历史最佳止损冒充真理。

### 5.1 数据生成要可辩护

可选残差/区块bootstrap、条件波动、跳跃/重尾、状态转换、跨资产联合路径和成交过程模拟。对比真实与合成的边际收益、自相关、波动聚集、尾部、最大回撤、跳空、交叉相关、成交率和成本；对参数不确定性外层抽样。

只有收盘收益、没有报价、成交量、价差、暂停和融资借券条件，不适合检验高换手或微观结构策略。大量合成路径仍只是同一生成假设下的抽样，不是更多真实市场历史。

### 5.2 OU半衰期推导与边界

离散均值回复价格过程：

\[
P_t-\mu=\phi(P_{t-1}-\mu)+\epsilon_t,\qquad |\phi|<1
\]

半衰期h满足 \(|\phi|^h=1/2\)，于是：

\[
h=\frac{\ln(0.5)}{\ln|\phi|},\qquad |\phi|=2^{-1/h}
\]

对常见的 phi∈(0,1)，这表示偏离均值单调缩至一半所需的期数；若 phi<0，偏离方向会交替，公式描述的是绝对幅度衰减。

书中OU止盈止损网格显示，回复速度、漂移、噪声和最大持有期会改变规则排序；当 \(\phi\) 接近1，过程近似随机游走，最优区域可能不清晰。长期预期收益反向时，盈亏区域也可翻转。

实际价格通常不服从单一固定OU。仅用训练窗估参，检验不同资产、状态和期限；均值漂移、跳跃、非线性状态会破坏单一OU导出的阈值。

## 6. 组合账本：从预测到可复算净回报

### 6.1 订单状态链

~~~text
信息可用 → 特征截点 → 预测 → 风险/组合批准 → 订单提交
  → 接受/拒绝 → 排队/部分成交/成交/撤单/过期
  → 更新持仓、现金、费用、应收应付 → 净值与收益
~~~

每次变更记录时间、订单ID、场所、数量、价格、剩余量、拒绝码、费用和来源。信号未成交时不能默认为收盘价成交。回放要处理资金不足、可卖数量、借券失败、触板队列、暂停和强平。

### 6.2 权重回测示例

约定目标仓位在t时点结束后产生，下一期收益由之前持仓赚取；真实项目要加公司行为、现金、未成交、融资借券和微观结构账本。

~~~python
import numpy as np
import pandas as pd

def weight_backtest(asset_total_returns, target_weight,
                    one_way_cost_bps, initial_weight=None):
    """
    target_weight[t] 是 t 时点信号完成后的目标仓位；
    它不能赚取信号形成前已发生的收益。
    """
    if not isinstance(asset_total_returns, pd.DataFrame) or not isinstance(target_weight, pd.DataFrame):
        raise TypeError("asset_total_returns and target_weight must be DataFrames")
    if (asset_total_returns.empty or asset_total_returns.shape[1] == 0
            or not asset_total_returns.index.is_unique
            or not asset_total_returns.index.is_monotonic_increasing
            or not asset_total_returns.columns.is_unique):
        raise ValueError("returns must have non-empty, ordered, unique dates and unique assets")
    if (not asset_total_returns.index.equals(target_weight.index)
            or not asset_total_returns.columns.equals(target_weight.columns)):
        raise ValueError("target_weight must align exactly with return dates and assets")
    r = asset_total_returns.astype(float)
    w = target_weight.astype(float)
    if not np.isfinite(r.to_numpy()).all() or not np.isfinite(w.to_numpy()).all():
        raise ValueError("returns and target weights must be finite and complete")
    one_way_cost_bps = float(one_way_cost_bps)
    if not np.isfinite(one_way_cost_bps) or one_way_cost_bps < 0:
        raise ValueError("one_way_cost_bps must be finite and non-negative")
    prev_w = w.shift(1)
    if initial_weight is None:
        initial_weight = pd.Series(0.0, index=r.columns)
    elif (not isinstance(initial_weight, pd.Series)
            or not initial_weight.index.equals(r.columns)
            or not np.isfinite(initial_weight.to_numpy(dtype=float)).all()):
        raise ValueError("initial_weight must be a finite Series aligned to asset columns")
    prev_w.iloc[0] = initial_weight

    gross = (prev_w * r).sum(axis=1, min_count=1)
    turnover = (w - prev_w).abs().sum(axis=1)
    trading_cost = turnover * one_way_cost_bps / 10_000.0
    net = gross - trading_cost
    if not np.isfinite(net.to_numpy(dtype=float)).all():
        raise ValueError("net returns must remain finite")

    return pd.DataFrame({
        "gross_return": gross,
        "turnover": turnover,
        "trading_cost": trading_cost,
        "net_return": net,
    })
~~~

此例假定成本率固定且全部成交，不适合有停牌、价格限制或容量瓶颈的股票模拟。正式系统拆分价差、手续费、冲击、融资、借券、税费和未成交机会成本，并使用订单量、成交量、方向、波动及场所状态。

### 6.3 总回报与账户净值

股票价格收益不同于账户总回报。总回报含现金分红、拆并股、配股、并购对价、现金替代、退市清算及外币组合汇兑；执行价仍是当时可交易的原始价格。外部申赎不能算策略盈利；dirty price已含应计利息/股息时不能重复计账。

分开报告毛交易PnL、费用后PnL、冲击后PnL、投资者净值回报和基准超额。注明时间加权或资金加权及外部现金流口径。

## 7. 绩效统计：从净值到不确定性

### 7.1 多维指标

|---|---|
| 策略画像 | 时间跨度、下注频率、持有期、做多比率、平均/最大AUM、杠杆、单名仓位 |
| 收益 | 总/年化收益、毛净差、基准超额、长短贡献、现金流口径 |
| 路径 | 最大回撤、长度、恢复时间、连续亏损和水下时间 |
| 尾部 | 偏度、峰度、分位损失、Expected Shortfall、跳空损失 |
| 实现 | 换手、成交率、价差、滑点、冲击、拒单/撤单、未成交机会成本 |
| 效率 | Sharpe、IR、PSR、DSR、概率校准 |
| 经济性 | 成本覆盖、盈亏平衡费率、AUM/参与率容量曲线 |

预测准确率解释模型，不替代组合PnL；Sharpe描述均值/波动，不涵盖路径、执行和容量风险。

### 7.2 Sharpe与年化假设

周期超额收益 \(r_t\) 的样本Sharpe为：

\[
\widehat{SR}=\frac{\bar r}{s_r}
\]

常见年化 \(\widehat{SR}_{ann}=\sqrt q\,\widehat{SR}\) 假定收益近似IID。存在自相关时，年化波动不等于简单乘 \(\sqrt q\)。长期方差可写为：

\[
\widehat{\Omega}=\hat\gamma_0+2\sum_{k=1}^{L}w_k\hat\gamma_k,\qquad
\widehat{SR}_{ann}=\frac{\sqrt q\,\bar r}{\sqrt{\widehat{\Omega}}}
\]

\(\hat\gamma_k\)为滞后协方差，\(w_k\)可用HAC截尾权重；L按持有期和样本检验。也可用区块bootstrap或较低频聚合。重叠持仓的日收益不可视为独立bet。

### 7.3 PSR：样本长度与非正态

Probabilistic Sharpe Ratio近似估计真实Sharpe超过阈值 \(SR^*\) 的概率：

\[
PSR(SR^*)=
\Phi\left(
\frac{(\widehat{SR}-SR^*)\sqrt{n-1}}
{\sqrt{1-\hat\gamma_3\widehat{SR}
+\frac{\hat\gamma_4-1}{4}\widehat{SR}^{\,2}}}
\right)
\]

n是观测数，\(\hat\gamma_3\)是偏度，\(\hat\gamma_4\)是**非超额峰度**（正态为3），\(\Phi\)为标准正态CDF。软件可能用不同小样本修正或峰度约定，应核对输入。

PSR仍依赖分布和样本独立性近似。序列相关、重叠收益、结构突变或有效样本远小于行数时，不应把未经依赖修正的PSR当精确概率。

### 7.4 DSR：多次试验后的比较门槛

Deflated Sharpe Ratio将PSR的参照值提高到多次试验中“最佳偶然Sharpe”的期望。常见近似为：

\[
SR^* \approx \sqrt{\operatorname{Var}(\widehat{SR}_i)}
\left[(1-\gamma)\Phi^{-1}\left(1-\frac{1}{N}\right)
+\gamma\Phi^{-1}\left(1-\frac{1}{Ne}\right)\right]
\]

再计算 \(DSR=PSR(SR^*)\)。N为试验数估计，\(\gamma\)为Euler–Mascheroni常数。具体实现对有效试验数、Sharpe估计方差和有限样本有约定，应引用公式和实现，不只报百分数。

DSR不能弥补未登记搜索、测试集窥视、错误成交、点时数据错误或依赖被忽略。并列报告raw Sharpe、DSR、候选集合、有效样本假设，并对合理N范围作敏感性分析。

### 7.5 回撤、集中度与下注频率

最大回撤从净值峰值向下计算，并注明日内/日终、是否含未实现损益及终止平仓。还报告持续时间、恢复期、分位回撤、连续亏损和压力路径。

按交易统计hit ratio前定义一笔交易何时结束；并发持仓、部分减仓、仓位翻转不可随意拆分以抬高胜率。配套报告：

\[
\text{expectancy}=p\,\bar W+(1-p)\,\bar L
\]

p为胜率，\(\bar W>0\)为平均盈利，\(\bar L<0\)为平均亏损。胜率本身不等于期望收益。正负收益、月份及交易分别检查贡献集中度；剔除最大几笔只用于诊断，不替代主结果。

## 8. 策略风险与组合风险不同

第15章把策略风险放在胜率、赔率和下注频率等参数扰动下分析；组合风险关注资金路径和持仓暴露。低波动策略仍可能因胜率轻微恶化而失去优势；机制尚可的策略也可能因仓位过大造成严重损失。

简化二元下注：赢时 \(+a\)，输时 \(-b\)，胜率p，则：

\[
E[X]=pa-(1-p)b,\qquad p_{BE}=\frac{b}{a+b}
\]

若一年独立下注n次，Sharpe推导会随n变化；真实交易的胜率、赔率、频率、仓位和市场状态常互相影响。IID Bernoulli失败概率会低估序列依赖风险。重采样或情景树要尽量保留依赖，并纳入参数不确定性。

## 9. A股与美股：相同原则，不同执行层

### 9.1 共同点

两市都用点时证券池与公司行为；按事件时间重放信号、订单、成交、持仓和净值；触价不等于成交；成本含价差、冲击、费用、融资/借券和容量；行情频率越低，执行精度越有限。

### 9.2 A股：按交易所、板块、产品和生效日期

保留交易所/板块、证券状态、价格限制、竞价阶段、停复牌、申报限制、最小价位、买卖可用数量、费率和交收日历。股票、ETF、债券和跨境产品可能有不同回转安排，不可跨产品复制规则。

要把“证券何时可再次卖出”和“交易后何时完成结算”作为两个约束字段。在适用上交所相关条款的证券中，买入后交收前不得卖出，回转交易品种除外；回测不能只记一个结算周期字段而漏掉当日卖出限制。美国T+1是标准结算周期，本身不等于普遍禁止同日买卖；账户购买力、保证金和券商限制应另行建模。

上交所《2026年修订交易规则》页面规定新规则自2026-07-06施行，并说明证券交收前不得卖出但回转交易品种例外；规则须记录生效日及品种例外，不能倒灌到历史。[上交所《交易规则（2026年修订）》](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)

重点检查：触及涨跌幅订单的成交队列；集合竞价与连续交易的信息时点；停复牌跳空退出；指数调样、风险状态和新股阶段；融券券源、费率、召回及账户权限。无历史借券数据时，将空头结果标作假设，或作长-only/悲观情景报告。

### 9.3 美股：多场所、时段和借券约束

区分SIP/NBBO综合行情与单场所direct feed；延长时段、报价条件、拍卖和场所流动性不能并成一个无语义价格。监管暂停、LULD和市场状态进入订单状态机。

SEC说明美国大部分证券交易的标准结算周期自2024-05-28改为T+1；结算周期不等同于当日买卖限制，现金/保证金账户及券商规则影响购买力。[SEC关于T+1生效的说明](https://www.sec.gov/newsroom/press-releases/2024-62)

空头须有点时券源和借券条件。SEC的Regulation SHO说明经纪商需要识别可借证券来源并满足交付要求；没有券源、费率、召回和账户数据时，不能假设负信号总可执行。[SEC Regulation SHO要点](https://www.sec.gov/investor/pubs/regsho.htm?os=0)

账户规则也会修订。FINRA于2026年发布日内保证金规则调整说明，生效与券商过渡安排须逐一核对；生产模拟不应写死旧的零售日内保证金门槛。[FINRA 2026日内保证金规则说明](https://syndication.finra.org/content/understanding-new-intraday-margin-requirements)

### 9.4 跨市场组合

统一结算货币、估值时点、汇率来源和现金收益。美国收盘时对A股下一交易日的信息不可见，反之亦然；异步日历不要按日期盲目前填后估相关性。记录本地时区、UTC、信号可用时刻和FX成交/fixing时间，并作滞后敏感性分析。

## 11. 高绩效异常的排查顺序

1. 时间戳：当时是否知道？供应商何时送达？何时能下单？
2. 证券身份：当时上市、可交易、在池中且状态正确吗？
3. 价格/公司行为：订单用原始可成交价吗？总回报含红利、拆股和退市清算吗？
4. 样本切分：标签重叠、全样本变换、调参窥视是否泄漏？
5. 成交状态：触板、停牌、跳空、部分成交、队列、券源和资金限制处理了吗？
6. 成本/容量：成本随规模变吗？空头、融资、冲击和未成交成本计入了吗？
7. 集中度：最大交易、月份、标的、行业、参数或状态支配结果吗？
8. 统计选择：试了多少方案？策略收益相关吗？Sharpe/PSR/DSR用什么依赖假设？
9. 稳健性与前向：近邻参数、成本压力、CPCV、情景与纸面交易支持机制吗？
10. 审计复现：能从原始输入重放到成交和净值吗？

不要先问模型是否不够复杂。模型越复杂，越需要严谨切分、完整试验账本、成本与容量验证。

### A.3 对书中结论和示例的实务校正

- CPCV增加路径数可改善某些估计，但路径高度相关、样本非平稳和研究选择仍带来不确定性；路径数不能当独立样本数。
- OU结果揭示已知过程上的止盈/止损响应，不证明真实市场服从OU，也不提供通用阈值。
- Sharpe/PSR/DSR有分布和样本假设；真实收益常自相关、重叠、厚尾或制度变化，要做依赖稳健估计。
- 书中Python/pandas/sklearn接口有版本背景；当前需验证权重传递、评分、索引端点、类别缺失和复现性。
- 统计校正依赖试验清单和收益序列正确。隐藏试验、测试窥视、错误成交和点时数据错误都不会被公式修复。
